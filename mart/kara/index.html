노래방 글꾸 만들기

액자글꾸

커뮤니티 글에 붙이는 노래방 글꾸(플레이어를 누르면 가사가 흐르는 노래 카드)를 여기서 바로 만들어요. 글에 올린 mp3 주소, 제목, 부르는 이름, 캐릭터 색, [분:초] 가사를 넣고 테마를 고른 뒤 만들기 → 복사 → 글쓰기 HTML 칸에 붙여요. 곡을 여러 개 넣으면 한 글에 카드가 차례로 들어가고 곡 사이에 코멘트 칸이 생겨요. 전부 이 화면 안에서만 돌아가요(어디로도 보내지 않아요). 테마 여섯 가지 모양은 글꾸 마트의 「노래방 글꾸」 칩에서 미리 볼 수 있어요(위 「글꾸」 탭).

만든 글

    사이트 흉내 미리보기 — 플레이어 ▶ 를 누르면 가사가 흘러요

    쓰는 법

    1. 커뮤니티 글쓰기에서 mp3 · 그림을 먼저 올리고(수정 › HTML 에서 https://img.kkangtong.xyz/post-audios/uploads/….mp3 주소를 복사) 여기 mp3 주소 칸에 붙여요. 표지 그림 주소는 없어도 돼요(레코드판만 돌아요).
    2. 가사는 한 줄에 [0:12] 가사 꼴로 적어요(LRC 파일 내용을 그대로 붙여도 돼요). 시간 없는 줄은 바로 위 줄의 작은 글(번역 · 원문)이 돼요.
    3. 곡 길이는 mp3 주소를 넣으면 저절로 읽어요(못 읽으면 3:24 처럼 직접 적어요). 비우면 마지막 가사 + 5초로 잡아요.
    4. 만들기 뒤 HTML 복사 → 글쓰기 HTML 칸에 통째로 붙여요. 화면 글에 「원곡 · 커버」 같은 말은 쓰지 않아요.

    만든 HTML 은 스크립트 없이 CSS 만으로 움직여요 — 플레이어를 누르면(초점이 오면) 가사 · 레코드판 · 시계가 같이 돌아요. 가사가 안 움직이면 카드 오른쪽 아래 「가사가 안 움직이면 ▸」, 멈추려면 가사창 위 ❚❚ 를 눌러요. 적은 내용은 이 브라우저에만 임시로 남고(다른 곳으로 보내지 않아요) 「비우기」로 지워요.
