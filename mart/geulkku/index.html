글꾸 마트

액자글꾸🧞지니

새 글꾸 틀 28개예요. 소품을 눌러 보세요 — 열리고 바뀌어요. 목록 위 캐릭터를 고르면 그 캐릭터 대사색으로 칠해지고, 카드의 📋 HTML 복사 → 커뮤니티 글쓰기 HTML 칸에 붙이면 끝이에요. 옛날 버전 글꾸는 목록 맨 아래에서 볼 수 있어요.

확장 없이도 써요 — 복사한 글에서 「✎」 주석 바로 뒤 글자(제목 · 이름 · 대사 …)만 바꾸면 돼요.

불러오는 중이에요…

받는 법

  1. 마음에 드는 글꾸의 🛒 담기를 눌러요(하나만이면 테마용 복사 · 폰에서도 돼요). 담은 뒤 머리줄 🛒 장바구니 → 🧾 계산하기(복사)나 📦 받기(파일)로 한 번에 받아요. 액자와 글꾸를 한 바구니에 같이 담아도 돼요.
  2. 채팅에서 글을 고르고 로그 복사 › 모양 칩 끝의 + 내 글꾸 › 마트에서 가져오기에 붙여 넣어요. 붙여넣기 칸에 바로 붙여 넣어도 알아서 가져와요.
  3. 「내 글꾸」 칩에 들어가요. 내 글꾸는 20개까지라, 쓰지 않는 것은 칩을 길게 눌러 지워요.
  4. 머리줄 📝 내 로그로 보기에 채팅 로그를 한 번 넣어 두면 목록의 카드가 전부 내 로그로 그려져요 — 넘기면서 마음에 드는 글꾸의 📋 HTML 복사를 누르면 내 로그가 든 완성 HTML 이 복사돼요. 끄면 표본 글로 돌아가요.

받는 것은 코드가 아니라 모양 데이터예요. 테마가 태그 · 스타일을 검사하고, 제목 · 메시지 · 추가 정보 · 꼬리 네 자리에 내 로그를 끼워 그려요. 미리보기의 글은 지어낸 표본이에요.

테마가 없어도 돼요 — 📋 HTML 복사를 누르면 미리보기 그대로의 완성 HTML(인라인 스타일만 · 스크립트 없음)이 복사돼요. 커뮤니티 글쓰기 칸에 붙여 넣고 글만 바꿔 쓰면 돼요. 글을 손으로 바꾸기 번거로우면 크게 보기의 🍽️ 시식하기에 채팅 로그를 붙여 넣어요 — 「이름: 글」 줄이면 이름으로, 없으면 빈 줄마다 번갈아 깡통 · 나로 나눠 끼워 주고, 실리태번 화면에서 복사한 글도 받아요.
