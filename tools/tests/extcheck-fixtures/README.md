# 확장 충돌 검사 시험용 가짜 확장

`tools/tests/extcheck.mjs` 와 사진 하네스가 검사 대상으로 쓰는 지어낸 확장 묶음이에요. 실제 확장 코드가 아니고, 규칙마다 걸림 · 안 걸림을 만들려고 겹치는 이름을 일부러 넣었어요. 실행하지 않고 글로만 읽어요.

| 폴더 | 하는 일 |
|---|---|
| Dice-Box · Story-Tools | 같은 명령 · 매크로 · 함수 도구 · 전역 · 설정 칸 · id · 단축키 · 맨 앞 사건 · CSS !important(다른 값) — 위험 · 주의 |
| Dice-Box-1.2.0 | Dice-Box 를 판 번호 붙은 폴더로 한 번 더 — 「두 번 깔림」 |
| Calm-Helper | 프롬프트 넣기(참고) · 공용 창구(Symbol.for st.*) · 없을 때만 만들기 · 이어 부르는 fetch 감싸기 · 같은 값 !important · 주석 안 이름 — 오탐 표로 빠지거나 안 세요 |
| Needs-New | 실리태번 판 부족 · 의존 확장 없음 · 꺼진 의존 확장 |
| Off-Ext | 꺼 둔 확장 — Dice-Box 와 같은 명령이 있어도 세지 않아요 |
| llm-translator-custom | 블루레몬에이드 내장 기능의 단독판 흉내 — 같은 설정 칸 · 명령은 오탐 표 twin, 대신 「내장 기능과 단독 확장」 한 줄 |
| Mood-Lights | 링크로 설치 전 검사용(설치돼 있지 않은 저장소 흉내) |
