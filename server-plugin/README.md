# ZIP 설치 도우미 1.1.0

블루레몬에이드 → 확장 → **ZIP 설치**를 켜고 새로고침하면 요술봉 메뉴에서 열 수 있어요. PC·모바일의 파일 선택기로 ZIP을 올리면 **현재 접속한 실리태번 서버**에 설치돼요.

## 처음 한 번 준비

브라우저 확장만으로는 서버 폴더를 덮어쓸 수 없어 작은 서버 플러그인이 필요해요. 별도 npm 설치는 없어요. 서버를 실행하는 PC 또는 Termux에서 해 주세요.

**1.0.0 도우미를 쓰고 있다면:** 삭제 기능은 도우미 1.1.0부터 지원해요. 테마를 업데이트한 뒤 아래 준비 명령을 한 번 더 실행하고 서버를 다시 켜 주세요. 기존 백업은 그대로 사용할 수 있어요.

**Windows:** 테마가 실리태번 확장 폴더에 설치돼 있으면, 서버를 종료하고 테마 안의 `server-plugin/setup-windows.cmd`를 두 번 눌러요. 완료되면 서버를 다시 켜 주세요. 테마 폴더에서 실리태번 위치를 자동으로 찾아요.

**Termux에서 준비하기:**

1. 실행 중인 실리태번 서버를 종료해요.
2. 홈 폴더에 `SillyTavern`을 기본 이름으로 설치했다면, 아래 두 줄을 **통째로** 붙여 넣어 실행해요.

```bash
cd ~/SillyTavern &&
node "data/default-user/extensions/blue-lemonade/server-plugin/setup.mjs"
```

**“ZIP 도우미를 준비했어요”**가 나오면 실리태번 서버를 다시 켜고 ZIP 설치 화면에서 **연결 확인**을 눌러요.

**폴더나 파일을 못 찾는다고 나오면**, 아래 명령으로 실제 경로를 찾아요.

```bash
find "$HOME" -type f -path '*/extensions/*/server-plugin/setup.mjs' 2>/dev/null
```

검색 결과의 **setup.mjs까지 포함한 전체 경로**를 복사하고, 위 `node` 명령의 따옴표 안 경로를 그 결과로 바꿔 실행해요. `node "찾은 전체 경로"` 모양이지만 **‘찾은 전체 경로’라는 글자를 그대로 입력하지 말고 실제 검색 결과로 바꿔 주세요.** 따옴표는 남겨요. 전체 경로를 쓰면 현재 폴더가 어디든 괜찮아요.

여러 경로가 나오면 지금 사용하는 실리태번에 설치된 테마를 골라요. 아무 결과도 없으면 블루레몬에이드를 최신 버전으로 업데이트한 뒤 다시 찾아 주세요. 다른 환경에서도 실제 `setup.mjs` 전체 경로를 `node`로 실행하면 돼요. 테마가 실리태번 밖에 있을 때는 뒤에 SillyTavern 폴더 경로를 두 번째 인자로 넣을 수 있어요.

설치기는 `plugins/blue-lemonade-zip`에 도우미를 복사하고 `config.yaml`의 `enableServerPlugins`를 켜요. 원래 설정·이전 도우미는 서버의 `.blue-lemonade-zip-setup`에 보관해요. 다른 서버 플러그인이 이미 들어 있는데 실행은 꺼져 있으면 자동 활성화하지 않고 설명을 보여줘요. 이 경우 다른 플러그인을 확인하고 설정을 직접 켠 다음 다시 실행하세요. 사용자 정의 config 파일로 서버를 실행 중이라면 그 파일의 `enableServerPlugins`도 직접 확인해야 해요.

## 매번 쓰는 방법

1. **ZIP 고르기** 또는 PC에서 파일 끌어 놓기.
2. 이름·버전·설치 폴더가 맞는지 확인해요. 같은 이름·저장소·폴더의 확장을 찾으면 업데이트 대상을 추천해요. 여러 후보면 직접 골라요.
3. **설치 내용 확인** → **설치** 또는 **백업하고 업데이트**를 눌러요.
4. 대화 작업을 마친 뒤 **새로고침해서 적용**을 눌러요. 켜짐·꺼짐 설정은 그대로예요.

ZIP 안에 `manifest.json`과 실행 JS/CSS가 있어야 해요. GitHub 소스 ZIP처럼 바깥 폴더가 있어도 인식해요. 여러 독립 확장이 함께 들어 있으면 하나씩 압축해 주세요. `.git`은 압축에서 빼 주세요. 확장 프로그램은 실행 코드이므로 믿을 수 있는 제작자의 파일만 설치하세요.

## 설치한 확장 삭제

1. **설치된 확장 관리 → 설치된 확장 목록**을 눌러요. 내 계정에 ZIP·링크로 설치한 확장이 함께 보여요.
2. 삭제할 확장을 고르고 **삭제 내용 확인**을 눌러요.
3. 이름·버전·폴더를 확인한 뒤 **백업하고 삭제**를 눌러요. 취소하면 파일은 바뀌지 않아요.
4. 대화 작업을 마치고 새로고침하면 확장이 실행되지 않아요. 되살리려면 **백업 복원**에서 **삭제 전 백업**을 선택해요.

확장 폴더 전체를 설치 목록 밖의 백업 위치로 옮겨 보관해요. 채팅·실리태번 설정·별도 데이터는 남고, 복원하면 기존 설정을 다시 사용할 수 있어요. **백업이 남으므로 디스크 공간을 비우는 기능은 아니에요.** 공용 확장과 복원 화면을 제공하는 블루레몬에이드 자체는 여기서 삭제하지 않아요.

## 업데이트와 복원

- 같은 경로의 파일은 교체하고, ZIP에 없는 기존 파일·`.git`·확장 내부 데이터는 남겨요. 채팅·실리태번 설정 파일을 수정하지 않아요. 제거된 구버전 파일을 반드시 지워야 하는 확장은 제작자의 별도 안내를 따르세요.
- 업데이트 전 폴더 전체를 해당 계정 폴더의 `.blue-lemonade-zip`에 백업해요. 화면의 **백업 복원**에서 되돌릴 수 있어요. 복원 직전 상태도 새 백업으로 남겨요. 백업에는 설치 폴더 안의 파일만 포함되며 채팅·별도 설정·외부 DB는 포함하지 않아요.
- 백업은 자동 삭제하지 않아요. 공간이 부족하면 설치를 완료하지 않으며, 폴더 교체 중 실패하면 원래 폴더를 돌려놓아요. 서버가 갑자기 꺼진 경우 다음 설치/백업 조회 시 중단된 교체를 복구해요.
- ZIP 64MiB / 해제 128MiB / 개별 파일 32MiB / 8,000항목까지, 기존 확장 백업은 512MiB / 20,000항목까지예요. 링크·경로 탈출·암호·손상 ZIP·이름 충돌은 거절해요.
- 관리자 계정에서 개인 확장 폴더만 관리해요. 모든 사용자 공용 확장·서버 플러그인·npm 의존성은 이 화면으로 설치하지 않아요. 서버 도우미 자체를 업데이트할 때는 새 버전의 준비 명령을 다시 실행하고 서버를 재시작해요.
- 다른 기기에서도 같은 서버에 접속할 수 있으면 사용할 수 있어요. 이 기능이 서버를 인터넷에 공개하거나 PC를 대신 켜 주지는 않아요.

검증 기준: SillyTavern 1.19.0 / Node.js 24. ZIP 해석은 SillyTavern이 제공하는 [yauzl](https://github.com/thejoshwolfe/yauzl)을 사용해요.
