## 처음 설정하기

1. **엔진**에서 사용할 서비스를 고르고 본인의 API 키·모델을 입력해 연결을 확인해요. 무료 브라우저 음성도 고를 수 있어요.
2. **목소리**에서 ‘계정에서 불러오기’ 또는 ‘직접 추가’로 사용할 목소리를 등록해요. MiniMax 목소리 목록은 JSON으로 붙여넣을 수도 있어요. 기본 목소리와 캐릭터별 목소리를 지정하세요.
3. 대사를 누르거나 메시지의 읽기 버튼으로 재생해요. **읽기**에서 자동 읽기·읽을 부분·감정 분석·원어 읽기·재생 표시를 조절해요.

처음 설치하면 자동 읽기·미리 만들기·감정 분석은 꺼져 있어요. 무료 브라우저 음성으로 대사 하나를 먼저 눌러 보세요. 감정 분석은 원할 때 분석용 API를 연결한 뒤 켜면 돼요. 기존 사용자의 켜짐·꺼짐 설정은 그대로 유지해요.

개인 계정의 목소리나 복제 음성은 포함되어 있지 않아요. 다른 계정의 목소리 ID는 해당 서비스에서 사용 권한이 없으면 재생되지 않아요. 기존 `lemon_voice` 설정과 등록 목록, 캐릭터 연결, 음성 캐시는 그대로 이어져요. 이전 TTS 확장이 켜져 있으면 중복 재생을 막기 위해 내장 TTS가 대기하므로 이전 확장을 끄고 새로고침하세요.

## 엔진 연결

키와 주소는 선택한 엔진의 설정에 입력해요. 각 서비스에서 제공하는 본인 계정의 키·모델·목소리 ID를 사용하세요. 서비스별 요금과 사용 가능 여부는 계정에 따라 달라요.

키를 저장하면 엔진 카드의 키 줄 아래에 **잔액 줄**이 보여요 (1.3.5). ElevenLabs는 남은 글자, Typecast는 남은 크레딧, OpenRouter는 키 한도가 있으면 남은 금액(없으면 쓴 금액), Cartesia는 이번 달 쓴 크레딧이에요. MiniMax는 API로 잔액을 알려 주지 않아 이번 달 이 엔진으로 쓴 글자와 결제 페이지 링크를 보여 줘요. 10분 동안 기억하고, ↻ 를 누르거나 키를 저장·연결 확인하면 바로 다시 물어요. OpenAI·Gemini·Azure·직접 서버·무료 엔진은 잔액 줄이 없어요.

**모델 목록은 늘 최신이에요** (1.3.7). ElevenLabs · OpenAI · OpenRouter · Gemini · Typecast 는 엔진 카드를 열 때 그 서비스가 주는 목록을 받아 와요 (12시간에 한 번, 이 브라우저에만 저장 · 모델 옆 ↻ 로 바로). 목록이 없는 MiniMax · Cartesia 는 테마가 아는 최신 목록이에요. 모델 이름은 한국어로 보여요 (예: 일레븐 v4 빠름 · 스피치 2.8 고음질 — 아직 안 나온 모델도). 목록에 없는 모델은 **직접 입력**으로 적을 수 있고, 골라 둔 모델은 목록에서 빠져도 바꾸지 않아요.

| 엔진 | 입력할 내용 |
|---|---|
| MiniMax | 계정의 API 키, API 지역, 음성 모델. 목소리는 계정 목록이나 본인의 voice ID로 등록해요. |
| OpenAI | API 키와 음성 모델. 기본 주소를 쓰거나 본인이 사용하는 주소를 입력해요. |
| OpenAI 호환 | 사용 중인 음성 서버의 API 주소·모델·목소리 ID. 서버가 요구할 때만 키를 넣어요. |
| OpenRouter | API 키와 오디오 출력을 지원하는 모델·목소리. |
| ElevenLabs | API 키, 음성 모델, 사용할 voice ID. |
| Google Gemini | API 키, 음성 생성 모델, 제공되는 목소리. |
| Azure | Speech 리소스 키와 지역, 목소리. |
| Typecast | API 키와 본인 계정에서 사용할 목소리. |
| Cartesia | API 키, 모델, 목소리 ID. |
| 브라우저 내장 | 키 없이 기기의 음성을 사용해요. 지원하는 음성과 언어는 기기마다 달라요. 파일 내려받기는 지원하지 않아요. |
| Google 번역 | 키 없이 실리태번의 Google 음성 경로를 사용해요. 해당 경로가 있는 실리태번이 필요해요. |

## 1.4.5

- 확장 창을 펼칠 때 TTS 탭이 보이는지 보는 계산을 화면 그리기 직전 한 번으로 줄였어요. 동작은 같아요.

## 1.4.4

- **듣는 언어** (읽기 → 본문과 제외할 내용): 자동 · 한국어 · 日本語 · English · 中文. 고르면 채팅을 어떤 언어로 하든 TTS 는 그 언어로 읽어요 (예: 영어로 채팅하고 일본어로 듣기). 기본은 **자동**이라 지금과 똑같아요.
- 그 언어가 아닌 줄만 **LLM 번역 애드온**의 연결 · 모델 · 키 · 용어집으로 옮겨요. 번역 애드온의 화면 번역(목표 언어 · 프롬프트)은 그대로예요. 화면 글 · 읽는 줄 강조도 그대로이고, 소리와 재생 막대 글만 고른 언어예요.
- 화면 번역문이나 원문이 이미 그 언어면 그대로 읽어요 (요청 없음 — 예: 화면 번역문이 한국어이고 한국어로 듣기). 아니면 원문을 옮겨요.
- 메시지마다 한 번에 옮기고(읽을 줄을 묶어 한 요청 · 아주 긴 답장은 번역 출력 한도에 맞춰 나눠서) 이 브라우저에 기억해요 — 다시 듣기 · 대사 클릭 · 미리 만들기 · 내려받기는 요청하지 않아요. 번역 기다리기 · 대사 분석이 끝난 뒤에 옮기고, 막대에 「일본어로 번역 중…」이 보여요. ■ 로 멈추거나 채팅을 바꾸면 번역 요청도 끊어요.
- 번역 애드온이 꺼져 있거나 번역 모델 · 키가 없으면 알림 한 번 뒤 원문으로 읽어요. 못 옮긴 줄(거절 · 오류)도 원문으로 읽고, 잠시(10분 · 일시 오류는 1분) 같은 줄로 다시 요청하지 않아요. 답의 줄 번호가 어긋나면 엉뚱한 줄을 읽지 않게 그 답은 버리고 한 번 더 물어요.
- 듣는 언어를 고르면 대사 분석의 **원어로 번역해서 읽기** 대신 이 언어로 읽고 (감정 · 화자 찾기는 그대로), **답장이 오는 동안 읽기**는 쉬어요 (답장이 다 온 뒤 한 번에 옮겨 읽어요).
- 엔진에 언어를 알려 줘요 (MiniMax 언어 보정 '글에 맞춰' · ElevenLabs 언어 코드 · 브라우저 음성 등은 고른 언어로 — 모델이 안 옮기고 돌려준 줄은 그 글의 언어로). 목소리 배정은 그대로라 그 언어를 읽을 수 있는 목소리를 골라 두세요.
- 미리 만들기는 유료 엔진 규칙 그대로예요 — 만들 줄이 있을 때만 옮기고, 못 옮긴 줄은 미리 만들지 않아요 (누르면 원문 · 잠시 뒤엔 다시 옮겨요).
- 데이터 탭의 **캐시 비우기**가 옮긴 글도 지워요 (번역이 마음에 안 들 때). 용어집을 고쳐도 이미 옮긴 줄은 그대로예요.

## 1.4.1

- **대화 색이 겹쳐 보이지 않게**: AI 가 같은 사람을 다른 색으로도 칠하면(예: 주인공을 다른 주황으로) 그 색은 줄을 따로 만들지 않고 그 사람 점의 오른쪽 아래에 작은 점으로 보여요. 진짜 동명이인이면 두 색에 같은 이름을 직접 적으면 두 줄로 나와요.
- 이름이 없는 새 색은 흐린 추천 이름 옆에 **✓ 이름** 단추가 생겨 누르면 바로 그 이름으로 정해요. 추천도 없이 한 번만 본 색은 숨겨요.

## 1.4.0

- **감정 세기 「약하게」가 ElevenLabs v3 · v4 에서도 차분해요**: 안정감만으로는 덜 들뜨지 않아서(ElevenLabs 는 감정을 글과 복제 원본에서 읽어요) 약하게면 글의 느낌표 · 물결 · 음표를 순하게 바꾸고, 말투를 안 고른 목소리엔 **덤덤하게**를 붙여요. 말투 칩에 「덤덤하게」도 생겼어요.
- **계정에서 바꾼 목소리 이름을 따라가요 (ElevenLabs)**: 계정에서 목소리 이름을 바꾸면 목소리 목록의 이름도 바뀌고, 「엔진」이 같은 이름의 목소리를 짝으로 골라요. 목록에서 직접 바꾼 이름은 그대로예요.
- **캐릭터마다 감정 세기**: 캐릭터별 목소리 · 대화 색 줄의 목소리 옆 칸(전체 · 약 · 보통 · 강)에서 바로 바꿔요 — 그 캐릭터가 읽는 목소리에만 (목소리 편집의 「감정 세기」와 같은 값). 옆의 설정 단추를 누르면 그 목소리 편집이 열려요. 카드 제목 옆 **?** 를 누르면 줄의 칸들이 무슨 뜻인지 펼쳐져요.
- **사용법(버전 표시를 누르면 열림)**: 캐릭터마다 목소리 정하기(엔진 · 대화 색 · 엑스트라 · 이름이 둘로 갈릴 때) · 감정 세기와 캐릭터마다 감정 · ElevenLabs 가 너무 들뜰 때(차분한 녹음으로 다시 복제)를 자세히 적었어요.
- **이 채팅의 캐릭터**: 대화 색이 없는 채팅(데우스 프리셋을 안 쓰는 경우)도 대화 색 카드 아래에 최근 메시지에 나온 캐릭터가 줄로 나와요 — 「이름: 「…」」 이름표 · 대사 분석의 화자 찾기 · 목소리를 정해 둔 이름. 줄마다 바로 목소리 · 감정 세기를 골라요.
- **같은 대사를 두 사람이 하면**(예: 둘 다 「다릅니다.」) 아래 줄을 눌러도 위 캐릭터 목소리로 읽던 것을 고쳤어요. 누른 줄의 캐릭터로 읽고, 미리 만들기도 같아요.
- 팁: 복제 목소리가 너무 들뜨면 차분한 녹음(예: MiniMax 로 만든 그 캐릭터 목소리)으로 다시 복제하면 v4 도 차분해져요 — v4 는 복제 원본의 말투를 가장 그대로 따라 해요.

## 1.3.9

- 내 대사(페르소나) 목소리가 없을 때 그 줄을 누르면 「○○(나) 대사도 자동 목소리로 읽을까요?」 — 여자 목소리 · 남자 목소리를 고르면 「나」가 자동이 되고 바로 읽어요. 목소리 탭에서 「나」 = 자동을 고를 때도 성별을 바로 물어요 (대사 분석을 기다리지 않게).

## 1.3.8

- **? 도움말**: 엔진 카드 · 목소리 편집의 항목 이름 옆 작은 **?** 를 누르면 그 항목 설명이 아래에 펼쳐져요.
- **키를 넣으면 바로 읽어요**: 키를 저장하거나 연결 확인을 하면 계정의 내 목소리를 넣고, 그 엔진 목소리가 하나도 없으면 목록을 바로 불러와 기본 목소리까지 정해요. 목소리 목록을 못 받으면(예: 목소리 읽기 권한이 빠진 ElevenLabs 키) 연결 확인 줄에 까닭이 보여요.
- **한 엔진이 안 되면 그 엔진 줄만 건너뛰어요**: 직접 입력 서버가 꺼졌거나 키를 거절해도 다른 엔진의 대사는 계속 읽어요. 직접 입력 서버가 응답하지 않으면 다시 시도하지 않고 까닭을 알려 줘요. 스트리밍으로 읽을 때도 그 답장 동안은 안 되는 엔진을 다시 기다리지 않아요.
- **「나」 자동** (캐릭터별 목소리 › 나): 페르소나도 목소리를 정하지 않은 화자처럼 엑스트라 목소리로 읽어요 (대사 분석이 성별 · 나이를 알려 줘요). 성별은 AI 답장 속 내 대사에서 배우고, 배우기 전엔 기본 목소리예요. 「내 대사」가 「읽지 않음」이면 자동을 고를 때 읽게 바꿔요. 「(없음)」이면 전처럼 읽지 않아요.
- **캐릭터마다 엔진 고정**: 「엔진」을 골라도 캐릭터별 목소리 · 대화 색의 고르기 칸 맨 위 **엔진별**에서 같은 사람의 다른 엔진 목소리를 고를 수 있어요 (예: `이름 · MiniMax`). 「엔진」과 다른 엔진을 고르면 그 캐릭터만 그 엔진으로 고정되고 줄에 작은 고정 칩이 생겨요 — 누르면 풀려요. 「엔진」을 「지정한 그대로」로 두면 고정은 쉬고, 다시 켜면 그대로 고정돼요. 키가 없는 엔진으로는 고정하지 않아요.
- **ElevenLabs 감정 세기**: 약하게 = 안정감 1 (가장 차분) · 강하게 = 감정이 붙은 줄만 안정감 −0.3 (v3 는 0 · 0.5 · 1 로 맞춰요) · 보통은 그대로예요. v3 에는 없는 원음 유사도 · 화자 강화 칸은 v3 에서 숨겨요.
- **ElevenLabs 말투** (v3 · v4): 목소리 편집이나 엔진 카드에서 말투 칩(피곤하게 · 무심하게 · 속삭이듯 …)을 고르면 줄마다 맨 앞에 그 오디오 태그를 붙여 읽어요. ElevenLabs 공식 안내에 있는 태그만 있고, 고른 말투는 목록 줄에 작게 보여요.
- **계정 맞춤 정리**: MiniMax 직접 입력 서버(집 PC 게이트웨이 등)는 계정 맞춤을 하지 않아요 (그 서버의 목소리만 알려 줘 나머지를 숨겼어요 — 숨긴 표시도 되돌려요). 목록에서 지운 목소리는 계정 맞춤 · 연결 확인으로 다시 들어오지 않아요 (직접 「불러오기」로 고르면 들어와요). 페이지를 열 때(서랍이 닫혀 있을 때)는 맞춤 · 잔액 요청과 「바꿀까요」 질문을 미뤘다가 목소리 · 엔진 탭이 보일 때 해요. 아니요 한 질문은 새 캐릭터가 없으면 다시 묻지 않아요. 미뤄 둔 질문은 엔진마다 차례로 물어요.

## 목소리 목록 · 캐릭터 목소리 (1.3.7)

- **목록 = 연결된 계정**: 키를 넣은 엔진의 목소리만 보여요. 계정에서 지운 목소리는 숨기고(목록 아래 「숨긴 목소리」 줄에서 지울 수 있어요, 캐릭터에 연결된 것은 남김), 계정에 새로 만든 내 목소리는 저절로 들어와요. 목소리 탭을 열 때 6시간에 한 번 맞춰요.
- **엔진** (캐릭터별 목소리 맨 위, 엔진이 둘 이상일 때): 엔진을 고르면 캐릭터 · 기본 · 나 · 내레이터 목소리를 그 엔진의 **같은 이름 목소리**로 바꿔 읽어요. 연결표는 그대로라 「지정한 그대로」로 언제든 되돌려요. 이름은 목소리 이름 · 괄호 앞 이름 · 괄호 안 영문 이름(예: `루시퍼 (Lucifer)`) · 다른 이름으로 맞춰요. 새 엔진에서 목소리를 불러오면 맞는 캐릭터가 있을 때 한 번 물어봐요.
- **목소리마다 모델**: 목소리 편집 › 모델에서 그 목소리만 쓸 모델을 고를 수 있어요 (예: 차분한 캐릭터만 다국어 v2). 「엔진 설정대로」면 엔진 카드의 모델이에요. 고른 모델은 목록 줄에 작게 보여요.
- **엑스트라 목소리** (캐릭터별 목소리 › 엑스트라, 기본 「자동」): 목소리를 정하지 않은 단역(카페 사장 · 편의점 점원 …)은 대사 분석이 알려 준 성별 · 나이로 그 엔진의 기본 목소리 가운데 맞는 것을 골라 읽어요. 같은 이름은 늘 같은 목소리이고, 엑스트라끼리는 되도록 다른 목소리예요. 「엑스트라 N명」을 펼쳐 자동으로 고른 목소리를 보고, 다른 목소리를 고르면 그 이름의 캐릭터 목소리로 고정돼요. 목소리 편집 › 엑스트라에서 남 · 여를 고른 목소리가 있으면 그것들 가운데서 골라요. 대사 분석이 꺼져 있거나 맞는 목소리가 없으면 전처럼 기본 목소리예요. 엔진의 기본 목소리 목록은 이 브라우저에만 저장해요.

## MiniMax 목록 JSON

‘목록 붙여넣기’에 아래와 같은 **JSON 배열**을 넣어요. `my_voice_id`를 본인이 사용할 수 있는 실제 ID로 바꾸세요. 다른 엔진은 ‘직접 추가’에서 엔진을 골라 등록해요.

```json
[
  {
    "voiceId": "my_voice_id",
    "name": "안내",
    "lang": "ko",
    "group": "내 목소리",
    "aliases": ["Guide"]
  }
]
```

- `voiceId`는 필수이며 `voice_id`도 받아요. `name`은 표시할 이름으로, 생략하면 ID를 사용해요.
- `lang`은 `ko`·`ja`·`en`·`zh` 또는 빈 값, `group`과 `aliases`는 선택 사항이에요.
- `model`에 해당 목소리의 생성 모델을 넣으면 MiniMax의 ‘목소리를 만든 모델’ 모드에서 사용할 수 있어요. 모르면 생략하세요.
- `autoGainDb`는 원본 음량 보정값을 알고 있을 때만 넣어요. 사용자가 정한 추가 음량 보정과 별도로 보관하며 ‘음량 고르게’를 켰을 때 중복 적용하지 않아요.
- 같은 ID를 다시 가져오면 목록의 이름·그룹·원어 등 제공된 항목을 갱신해요. 사용자 음량 슬라이더 값은 유지해요. API 키는 이 목록에 넣지 않아요.

## 읽기와 감정

**화자 찾기** (1.3.6, 대사 분석 안의 스위치, 기본 켬): 대사 색이나 이름표가 없어서 누구 말인지 알 수 없던 대사는 대사 분석이 서술과 앞뒤 대사를 보고 누구 말인지 골라요. 고를 수 있는 이름은 지금 캐릭터 · 나 · 목소리를 지정한 이름 · 그룹 멤버 · 이 채팅에서 배운 이름이고, 그 이름에 지정한 캐릭터별 목소리로 읽어요. 대사 색으로 이미 정해진 대사는 그대로예요. 대사 분석이 꺼져 있거나 엔진이 없으면 전처럼 메시지를 보낸 캐릭터 목소리예요.

대화문만, 서술 포함, 행동 제외, 전부 중에서 읽을 부분을 골라요. 캐릭터·나·내레이터의 목소리를 각각 연결할 수 있고, 대화 색이나 이름으로 화자를 찾을 수 있어요. 번역을 기다렸다가 읽기, 대사 소리 미리 만들기, 캐시 재사용, 음량 고르기, 대사 사이 쉼도 지원해요.

**읽기 → 본문과 제외할 내용**에서 상태창 등 읽지 않을 부분을 정해요. ‘건너뛸 태그’는 태그 안쪽 글까지 제외하고, ‘추가로 지울 글(정규식)’은 규칙에 일치한 부분만 제외해요. 태그 자체는 자동 정리하므로 정규식은 보통 비워 둬요. 태그만 지우는 규칙은 내용 제외나 감정 힌트를 방해할 수 있어요. 속마음은 **읽을 부분 → 직접 설정 → 속마음**에서 정해요.

새 사용자는 상태창·계획·미디어 태그와 코드 블록을 제외하고, `momentum`·`visuals`도 제외해요. 별도 태그가 없는 본문이나 `prose` 안의 내용은 읽어요. 기존 필터는 그대로 이어지며, **본문 필터 기본값** 버튼에서 설명을 확인한 뒤 원하는 경우에만 바꿀 수 있어요. 이 버튼은 정규식을 비우고 감정 태그 사용을 켜며, 읽을 부분·속마음·목소리·분석 연결·발음 사전은 유지해요.

PC와 모바일 모두 짧은 설정은 공간에 따라 두 칸으로 놓고, 긴 주소·JSON·정규식은 한 줄 너비를 사용해요. 좁은 화면이나 큰 글씨에서는 한 칸으로 바뀌어요. 발음 사전과 정규식은 고급 항목을 열어 설정할 수 있어요.

감정 분석은 **읽기 → 대사 분석**에서 따로 설정해요. 실리태번의 현재 연결, 실리태번에 저장한 공급자·모델, 별도의 OpenAI 호환 주소 중 하나를 고를 수 있어요. 분석 모델이 감정과 번역을 정하며 실제 목소리를 만드는 TTS 엔진은 엔진 탭의 설정을 사용해요. 감정 분석을 켰다고 모든 음성이 같은 강도로 감정을 표현하는 것은 아니에요.

감정 표현은 엔진·모델·목소리가 지원하는 범위에 따라 달라요. MiniMax 2.8 처럼 속삭임이 없는 모델은 속마음 · 속삭이는 대사만 같은 등급의 2.6 모델(hd → 2.6-hd, turbo → 2.6-turbo)로 읽어요. 분석이 ‘차분’이라고 한 대사는 감정을 따로 보내지 않고 엔진이 글을 보고 정하며, ‘외침’은 MiniMax 에서 화남으로 바꾸지 않고 음량만 키워요. **읽기 → 대사 분석 → 감정 세기**에서 약하게(감정을 따로 보내지 않고 엔진이 글을 보고 정함, 속삭임만 유지) · 보통 · 강하게(MiniMax speech-2.8 에서 감정에 맞춰 숨 · 웃음 · 한숨 · 헉 · 들이쉬는 소리를 줄 앞에 붙임)를 골라요. ElevenLabs 는 약하게면 안정감 1, 강하게면 감정이 붙은 줄의 안정감을 0.3 낮춰요 (1.3.8). 같은 곳의 **속마음**에서 속삭임 또는 일반(속삭이지 않고 엔진이 글을 보고 감정을 정함 — 대사 분석은 대사만 봐요)을 골라요. OpenAI의 일부 모델은 말투 지시를 받지 않고, OpenAI 호환 서버의 지시문 지원도 서버마다 달라요. Azure 스타일이나 ElevenLabs 태그 등도 지원 목소리·모델에서만 효과가 있어요. 브라우저 내장·Google 번역은 감정 파라미터를 지원하지 않아요.

**읽기 → 재생 → 재생 표시**에서 색깔만 / 색깔 + 밑줄 / 밑줄만을 고를 수 있어요. 재생 중 바로 반영되고, ‘읽는 대사 강조’를 끄면 표시하지 않아요. 원래 글꼴·색·서식은 유지해요.

내장 애드온을 끄면 재생·대기·미리 만들기를 중지하고 새 요청을 보내지 않아요. 서비스에 이미 도착한 요청의 처리나 요금까지 취소되는 것은 아니에요. 실리태번 현재 연결의 이미 전송된 분석은 본체가 별도 취소 신호를 받지 않아 응답 대기만 끝내고 늦은 결과를 사용하지 않아요.

## 저장되는 정보

API 키는 실리태번 설정에 저장되며 TTS 설정 내보내기에서 제외돼요. 음성 엔진에는 읽을 글이 전송되고, 감정 분석을 사용하면 선택한 분석 서비스에 대사·화자 이름·주변 서술·번역문 일부가 전송돼요. 분석 결과는 채팅에, 만든 음성은 이 브라우저의 캐시에 저장돼요. 데이터 탭에서 캐시를 비울 수 있어요.

설정 가져오기는 API 키를 가져오지 않으며, 키가 있는 엔진의 서버 주소를 임의로 바꾸지 않아요. 직접 입력한 주소가 다른 서버를 가리키는지 저장 전에 확인하세요.

## 1.5.0 소리 대본과 효과음

메시지 아래 소리 대본 편집 버튼에서 원문을 바꾸지 않고 대사·화자·목소리·감정·순서·음량을 고칩니다. 줄 추가/제외/삭제, 실행 취소/재실행, 쉼, 한 줄 재생/재생성, 메시지별 저장/원본 복원을 지원합니다. 원문·번역·스와이프가 달라지면 낡은 편집을 적용하지 않습니다. 다시 생성은 선택한 줄의 음성 서비스 사용량이 생깁니다.

읽기 → 효과음 · 소리 대본에서 채팅 효과음을 켤 수 있습니다(기본 꺼짐). 자동 찾기는 기존 대사 분석 연결을 사용하고, 같은 분석 요청에서 실제 발생한 소리만 골라 최대 8개를 연결합니다. 맞는 로컬 음원이 없으면 생략합니다. 유료 효과음 자동 생성은 하지 않습니다. 효과음 재생 자체는 생성 크레딧을 사용하지 않으며 분석 비용은 기존 서비스 조건을 따릅니다.

1.5.0에서 MultiCast 효과음 47개를 도입했고 1.5.1에서 생활 효과음 16개, 1.5.3에서 6개, 1.5.7에서 찰싹 2개, 1.6.0에서 친밀한 장면 효과음 10개를 더해 총 81개입니다. 이름·분류·키워드 검색, 미리듣기, 사용자 음원 및 팩 가져오기/내보내기를 지원합니다. 사용자 음원은 별도 브라우저 IndexedDB에 저장되므로 다른 기기로 옮길 때 효과음 팩이 필요합니다. 순차/겹치기/반복, 전체 효과음 및 줄별 음량, 최대 3개 반복, 정지·일시정지가 연결됩니다. WAV는 음성·쉼·효과음을 합쳐 원래 속도(1배속)로 저장합니다. 브라우저 내장 목소리는 WAV 저장을 지원하지 않으며 한 번에 10분까지 저장합니다.

출처: [MultiCast-TTS / JINSIN2](https://github.com/JINSIN2/MultiCast-TTS), 기준 f48ebeef9b19d814bf8d4568af13613544007e63. 포팅 코드의 MIT 전문은 LICENSE-MultiCast.txt, 전체 고지는 NOTICE.md, 번들 음원의 원본 URL·해시와 CC0 표시 근거는 sfx/SOURCES.json에 보존합니다. 개별 음원의 최초 제작자/원출처까지 독립 검증한 것은 아닙니다.

## 1.5.2 가져온 효과음 출처 보존

효과음 팩 `sounds[].credit`의 원작자·HTTPS 출처·라이선스·변경 내역을 저장하며 보관함, 팩 내보내기, 출처 복사와 WAV 기록에 함께 넣습니다. 제공된 정보이며 라이선스를 자동 검증한 것으로 표시하지 않습니다. 이름과 실제 음원 SHA256이 정확히 맞는 단 하나의 항목에 한해 예전 `credits[]` 형식을 옮깁니다. 같은 음원을 다시 가져오면 빈 출처만 보완하고 기존 이름·연결 단어·반복 설정·꺼짐 상태를 바꾸지 않습니다. 출처가 없는 파일은 정보 없음으로 표시합니다.

Syncthing으로 설정의 목록만 옮겨지고 새 브라우저의 IndexedDB 파일이 비어 있을 때도 팩 가져오기로 복원할 수 있습니다. 음원 SHA256이 같고 기존 항목이 하나로 정해지면 기존 ID에 없는 음원만 채우고 대본 연결·사용자 편집·꺼짐 상태를 유지합니다. 이미 있는 파일은 덮어쓰지 않습니다.

## 1.5.3 생활 효과음 6개 추가

휴대폰 진동 한 묶음·의자 한 번 끌기·펜 뚜껑 딸깍·냉장고 문 여닫는 소리·전기주전자 끓는 소리·양치질을 더해 내장 효과음이 69개가 됐습니다. 모두 BigSoundBank(Joseph SARDIN, CC0 1.0) 음원에서 한 동작 또는 짧은 연속 구간을 발췌해 음량·페이드·MP3 인코딩을 조정했으며 [원본·변경 내역·SHA-256](sfx-extra/SOURCES.json)에 기록합니다. 전기주전자와 양치질은 서술의 “한동안”·“5초 동안” 같은 표현에 따라 최대 8초까지 재생 길이를 정하고, 휴대폰 진동·냉장고 문처럼 되풀이되는 동작은 “두 번” 같은 횟수를 최대 4회까지 읽습니다. 소리 대본에서는 반복·길이를 직접 고를 수 있습니다. 효과음 팩으로 같은 음원을 이미 가져왔다면 보관함에 내 음원과 내장 소리가 함께 보이며, 내 음원을 보관함에서 삭제해도 내장 소리는 남습니다.

## 1.5.4 누른 대사 앞 지문의 효과음 · 다른 확장과 연동

지문을 읽지 않는 설정에서는 메시지를 통째로 읽지 않고 대사를 눌러 읽는 일이 많은데, 그 경로에는 효과음이 붙지 않아 효과음이 한 번도 나지 않았습니다. 1.5.4부터 대사를 눌러 읽으면 그 대사 바로 앞 지문(서술·행동)에서 찾은 효과음을 먼저 들려줍니다(효과음 · 소리 대본의 「누른 대사 앞 지문의 효과음도」, 기본 켜짐). 저장된 분석이 없으면 먼저 분석하고, 분석이 꺼져 있으면 전처럼 대사만 읽습니다.

다른 확장은 `window.LemonVoice.readText({ text, name })`로 글을 채팅 메시지처럼 읽게 할 수 있습니다(대사·지문·속마음 나누기, 읽을 글 설정, 화자별 목소리, 태그 감정, 발음 사전 적용; 대사 분석·효과음·듣는 언어·캐시 기록은 없음). `window.LemonVoice.stop()`으로 멈춥니다.

## 1.5.5 다른 확장의 글도 메시지와 똑같이

`readText`가 넘겨받은 글을 메시지와 같은 길로 읽습니다. 읽을 글 설정과 화자별 목소리뿐 아니라 대사 분석(화자 찾기·감정)·효과음·듣는 언어 번역·발음 사전까지 TTS 설정을 그대로 따릅니다. `only: { text, index }`를 주면 누른 대사만 읽고, 그 앞 지문의 효과음도 함께 납니다(글이 맞지 않으면 index 번째 대화문). 같은 글은 분석을 다시 묻지 않습니다(최근 8개).

## 1.5.6 긴 답장의 효과음

대사 분석에 보내는 지문 발췌가 맥락 예산(기본 1,200자)에 묶여 있어 긴 답장에서는 중간 지문이 통째로 빠졌고, 모델이 그 소리를 볼 수 없었습니다. 1.5.6부터 효과음용 예산 4,000자를 따로 두고, 넘치면 효과음 낱말(내장·내 효과음의 연결 단어)이 든 문장을 먼저 전부 넣은 뒤 나머지를 앞뒤에서 채웁니다. 저장된 분석은 프롬프트가 달라져 다음 읽기 때 한 번 다시 받습니다. 대사를 눌러 읽을 때 그 대사가 마지막 대사면 그 뒤 지문의 효과음도 대사 뒤에 이어서 납니다.

## 1.5.7 찰싹 2개 · 효과음 넓이 · 세기

- **찰싹 한 번**(손바닥)과 **엉덩이 찰싹 (연속)**을 더했습니다(BigSoundBank, Joseph SARDIN, CC0). 분석이 친밀한 장면의 살 때리는 소리도 효과음으로 다루도록 지시문에 적었습니다. 전엔 「타격」이 slap 낱말을 받았지만 모델이 그 장면의 소리로 고르지 않았습니다.
- 분석이 효과음마다 **세기**(1 분명한 소리 · 2 소리 나는 동작 · 3 희미한 소리)를 함께 답하고 최대 12개까지 받습니다. 효과음 · 소리 대본의 **효과음 넓이**(적음 · 보통 · 많이)는 저장된 신호를 재생 때 거를 뿐이라, 바꿔도 분석을 다시 하거나 음성을 다시 만들지 않습니다. 적음은 세기 1만 3개까지, 보통은 1~2를 8개, 많이는 전부 12개까지입니다. WAV 저장은 적어도 보통으로 넣습니다. 지시문이 바뀌어 저장된 분석은 다음 읽기 때 한 번 다시 받습니다.

## 1.5.8 효과음 찾을 지문 글자

1.5.6의 효과음용 예산 4,000자를 설정으로 옮겼습니다(1.5.8). 읽기 → 효과음 · 소리 대본 → 「효과음 찾을 지문 글자」(효과음과 자동 찾기를 켜면 보임, 기본 4,000 · 1,000~40,000)가 대사 분석에 보내는 지문(서술·행동)의 최대 글자입니다. 긴 답장에서 효과음을 놓치면 늘리고, 분석 요청의 토큰을 아끼려면 줄입니다. 모델이 읽는 토큰 수는 한국어·일본어가 글자 수와 비슷하고 영어는 그 1/4쯤입니다. 범위 밖 값은 범위로 자르고, 숫자가 아니면 4,000으로 돌아갑니다. 바꾸면 예산을 넘는 긴 답장의 프롬프트가 달라져 저장된 분석을 다음 읽기 때 한 번 다시 받고, 예산 안에 드는 답장은 그대로입니다.

## 1.5.9 대사 동안 이어지는 소리

- 지속 가능한 소리(리듬·환경음, 내 효과음의 반복)는 대사를 눌러 읽을 때 그 대사가 끝날 때까지 반복합니다. 전에는 한 번만 나서 대사보다 먼저 끝났습니다.
- 분석이 대화 내내 이어지는 동작(스팽킹·키스·빗소리·타이핑 등)에 `ongoing`과 멈추는 자리 `stopAfter`를 함께 답합니다. 그 범위의 어느 대사를 눌러도 소리가 밑에 깔리고, 메시지 전체 읽기와 WAV 저장에서는 끝까지 반복하다 멈추는 대사 앞에서 끝납니다. 저장된 분석은 지시문이 바뀌어 한 번 다시 받습니다.

## 1.6.0 친밀한 장면 효과음 10개 · 번역 전·후 분석 한 번만

- freesound(CC0)에서 **핥기 한 번·핥기 (연속)**(SundayRecords), **키스**(noahpardo)·**키스 (연속)**(freesound), **찔꺽**(SoundDesignForYou)·**찔꺽 (연속)**(tiddles451), **침대 삐걱**(cabusta9)·**침대 삐걱 (연속)**(bmusic92), **꿀꺽**(magnuswaker)·**꿀꺽 (연속)**(DeVern)을 더했습니다. (연속) 소리는 지속 가능한 소리라 대사를 눌러 읽을 때 그 대사 동안 반복하고, 분석이 이어지는 동작(`ongoing`)으로 답하면 멈추는 대사까지 깔립니다. 분석 지시문에 핥기·젖은 소리·침대 삐걱·삼키기도 소리라고 적었습니다. 내장 효과음은 81개입니다.
- 저장된 분석의 키에서 화면 번역문을 뺐습니다. 전에는 번역 기다리기를 끄고 자동 번역을 쓰면 번역 전에 한 번, 번역문이 붙은 뒤 한 번 더 같은 답장을 분석했습니다. 이제 번역이 뒤에(또는 분석 중에) 붙어도 번역 전 분석을 그대로 쓰고, 1.5.9 이전에 번역문과 함께 저장된 키도 그대로 맞춥니다. 요청 자체에는 번역문이 있으면 여전히 참고로 넣습니다.
- 대사 분석 응답이 JSON이 아니면 모델이 글로만 답했는지, 빈 답인지 구분해 알려 주고 진단 기록에 응답 앞부분(비밀값은 가림)을 남깁니다. 효과음 목록이 늘어 지시문이 바뀌었으므로 저장된 분석은 다음 읽기 때 한 번 다시 받습니다.
