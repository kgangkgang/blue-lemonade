# TTS 1.3.9

블루 레몬에이드의 내장 애드온입니다. 설정의 애드온 목록에서 **TTS**를 켜고 세부 설정을 열어요. 처음에는 꺼져 있으며, TTS를 사용할 수 있는 사용 모드는 ‘확장’ 또는 ‘테마 + 확장’입니다.

TTS 이름 옆 **버전 표시**를 누르면 무료 음성으로 시작하기·엔진별 연결·목록 등록·문제 해결을 볼 수 있어요. 사용법을 여는 것만으로 API를 호출하지 않아요.

**블루 레몬에이드 → 확장 → TTS → 표시할 위치 → 확장 탭에 TTS 설정 표시**로 실리태번 확장 탭에 설정을 꺼내 둘 수 있어요. 번역 확장처럼 기본은 켬이며, 끄고 켜면 바로 반영돼요. 숨겨도 블루 레몬에이드의 세부 설정과 켜 둔 요술봉 메뉴는 쓸 수 있어요. 표시 위치만 바뀌고 목소리·재생 설정은 유지해요. TTS 기능 자체가 꺼져 있으면 표시 옵션만으로 기능을 불러오지 않아요.

## 처음 설정하기

1. **엔진**에서 사용할 서비스를 고르고 본인의 API 키·모델을 입력해 연결을 확인해요. 무료 브라우저 음성도 고를 수 있어요.
2. **목소리**에서 ‘계정에서 불러오기’ 또는 ‘직접 추가’로 사용할 목소리를 등록해요. MiniMax 목소리 목록은 JSON으로 붙여넣을 수도 있어요. 기본 목소리와 캐릭터별 목소리를 지정하세요.
3. 대사를 누르거나 메시지의 읽기 버튼으로 재생해요. **읽기**에서 자동 읽기·읽을 부분·감정 분석·원어 읽기·재생 표시를 조절해요.

처음 설치하면 자동 읽기·미리 만들기·감정 분석은 꺼져 있어요. 무료 브라우저 음성으로 대사 하나를 먼저 눌러 보세요. 감정 분석은 원할 때 분석용 API를 연결한 뒤 켜면 돼요. 기존 사용자의 켜짐·꺼짐 설정은 그대로 유지해요.

개인 계정의 목소리나 복제 음성은 포함되어 있지 않아요. 다른 계정의 목소리 ID는 해당 서비스에서 사용 권한이 없으면 재생되지 않아요. 기존 `lemon_voice` 설정과 등록 목록, 캐릭터 연결, 음성 캐시는 그대로 이어져요. 이전 TTS 확장이 켜져 있으면 중복 재생을 막기 위해 내장 TTS가 대기하므로 이전 확장을 끄고 새로고침하세요.

## 엔진 연결

키와 주소는 선택한 엔진의 설정에 입력해요. 각 서비스에서 제공하는 본인 계정의 키·모델·목소리 ID를 사용하세요. 서비스별 요금과 사용 가능 여부는 계정에 따라 달라요.

키를 저장하면 엔진 카드의 키 줄 아래에 **잔액 줄**이 보여요 (1.3.5). ElevenLabs는 남은 글자, Typecast는 남은 크레딧, OpenRouter는 키 한도가 있으면 남은 금액(없으면 쓴 금액), Cartesia는 이번 달 쓴 크레딧이에요. MiniMax는 API로 잔액을 알려 주지 않아 이번 달 이 엔진으로 쓴 글자와 결제 페이지 링크를 보여 줘요. 10분 동안 기억하고, ↻ 를 누르거나 키를 저장·연결 확인하면 바로 다시 물어요. OpenAI·Gemini·Azure·직접 서버·무료 엔진은 잔액 줄이 없어요.

**모델 목록은 늘 최신이에요** (1.3.7). ElevenLabs · OpenAI · OpenRouter · Gemini · Typecast 는 엔진 카드를 열 때 그 서비스가 주는 목록을 받아 와요 (12시간에 한 번, 이 브라우저에만 저장 · 모델 옆 ↻ 로 바로). 목록이 없는 MiniMax · Cartesia 는 테마가 아는 최신 목록이에요. 모델 이름은 한국어로 보여요 (예: 일레븐 v4 빠름 · 스피치 2.8 고음질 — 아직 안 나온 모델도). 목록에 없는 모델은 **직접 입력**으로 적을 수 있고, 골라 둔 모델은 목록에서 빠져도 바꾸지 않아요.

| 엔진 | 입력할 내용 |
|---|---|
| MiniMax | 계정의 API 키, API 지역, 음성 모델. 목소리는 계정 목록이나 본인의 voice ID로 등록해요. |
| OpenAI | API 키와 음성 모델. 기본 주소를 쓰거나 본인이 사용하는 주소를 입력해요. |
| OpenAI 호환 | 사용 중인 음성 서버의 API 주소·모델·목소리 ID. 서버가 요구할 때만 키를 넣어요. |
| OpenRouter | API 키와 오디오 출력을 지원하는 모델·목소리. |
| ElevenLabs | API 키, 음성 모델, 사용할 voice ID. |
| Google Gemini | API 키, 음성 생성 모델, 제공되는 목소리. |
| Azure | Speech 리소스 키와 지역, 목소리. |
| Typecast | API 키와 본인 계정에서 사용할 목소리. |
| Cartesia | API 키, 모델, 목소리 ID. |
| 브라우저 내장 | 키 없이 기기의 음성을 사용해요. 지원하는 음성과 언어는 기기마다 달라요. 파일 내려받기는 지원하지 않아요. |
| Google 번역 | 키 없이 실리태번의 Google 음성 경로를 사용해요. 해당 경로가 있는 실리태번이 필요해요. |

## 1.3.9

- 내 대사(페르소나) 목소리가 없을 때 그 줄을 누르면 「○○(나) 대사도 자동 목소리로 읽을까요?」 — 여자 목소리 · 남자 목소리를 고르면 「나」가 자동이 되고 바로 읽어요. 목소리 탭에서 「나」 = 자동을 고를 때도 성별을 바로 물어요 (대사 분석을 기다리지 않게).

## 1.3.8

- **? 도움말**: 엔진 카드 · 목소리 편집의 항목 이름 옆 작은 **?** 를 누르면 그 항목 설명이 아래에 펼쳐져요.
- **키를 넣으면 바로 읽어요**: 키를 저장하거나 연결 확인을 하면 계정의 내 목소리를 넣고, 그 엔진 목소리가 하나도 없으면 목록을 바로 불러와 기본 목소리까지 정해요. 목소리 목록을 못 받으면(예: 목소리 읽기 권한이 빠진 ElevenLabs 키) 연결 확인 줄에 까닭이 보여요.
- **한 엔진이 안 되면 그 엔진 줄만 건너뛰어요**: 직접 입력 서버가 꺼졌거나 키를 거절해도 다른 엔진의 대사는 계속 읽어요. 직접 입력 서버가 응답하지 않으면 다시 시도하지 않고 까닭을 알려 줘요. 스트리밍으로 읽을 때도 그 답장 동안은 안 되는 엔진을 다시 기다리지 않아요.
- **「나」 자동** (캐릭터별 목소리 › 나): 페르소나도 목소리를 정하지 않은 화자처럼 엑스트라 목소리로 읽어요 (대사 분석이 성별 · 나이를 알려 줘요). 성별은 AI 답장 속 내 대사에서 배우고, 배우기 전엔 기본 목소리예요. 「내 대사」가 「읽지 않음」이면 자동을 고를 때 읽게 바꿔요. 「(없음)」이면 전처럼 읽지 않아요.
- **캐릭터마다 엔진 고정**: 「엔진」을 골라도 캐릭터별 목소리 · 대화 색의 고르기 칸 맨 위 **엔진별**에서 같은 사람의 다른 엔진 목소리를 고를 수 있어요 (예: `이름 · MiniMax`). 「엔진」과 다른 엔진을 고르면 그 캐릭터만 그 엔진으로 고정되고 줄에 작은 고정 칩이 생겨요 — 누르면 풀려요. 「엔진」을 「지정한 그대로」로 두면 고정은 쉬고, 다시 켜면 그대로 고정돼요. 키가 없는 엔진으로는 고정하지 않아요.
- **ElevenLabs 감정 세기**: 약하게 = 안정감 1 (가장 차분) · 강하게 = 감정이 붙은 줄만 안정감 −0.3 (v3 는 0 · 0.5 · 1 로 맞춰요) · 보통은 그대로예요. v3 에는 없는 원음 유사도 · 화자 강화 칸은 v3 에서 숨겨요.
- **ElevenLabs 말투** (v3 · v4): 목소리 편집이나 엔진 카드에서 말투 칩(피곤하게 · 무심하게 · 속삭이듯 …)을 고르면 줄마다 맨 앞에 그 오디오 태그를 붙여 읽어요. ElevenLabs 공식 안내에 있는 태그만 있고, 고른 말투는 목록 줄에 작게 보여요.
- **계정 맞춤 정리**: MiniMax 직접 입력 서버(집 PC 게이트웨이 등)는 계정 맞춤을 하지 않아요 (그 서버의 목소리만 알려 줘 나머지를 숨겼어요 — 숨긴 표시도 되돌려요). 목록에서 지운 목소리는 계정 맞춤 · 연결 확인으로 다시 들어오지 않아요 (직접 「불러오기」로 고르면 들어와요). 페이지를 열 때(서랍이 닫혀 있을 때)는 맞춤 · 잔액 요청과 「바꿀까요」 질문을 미뤘다가 목소리 · 엔진 탭이 보일 때 해요. 아니요 한 질문은 새 캐릭터가 없으면 다시 묻지 않아요. 미뤄 둔 질문은 엔진마다 차례로 물어요.

## 목소리 목록 · 캐릭터 목소리 (1.3.7)

- **목록 = 연결된 계정**: 키를 넣은 엔진의 목소리만 보여요. 계정에서 지운 목소리는 숨기고(목록 아래 「숨긴 목소리」 줄에서 지울 수 있어요, 캐릭터에 연결된 것은 남김), 계정에 새로 만든 내 목소리는 저절로 들어와요. 목소리 탭을 열 때 6시간에 한 번 맞춰요.
- **엔진** (캐릭터별 목소리 맨 위, 엔진이 둘 이상일 때): 엔진을 고르면 캐릭터 · 기본 · 나 · 내레이터 목소리를 그 엔진의 **같은 이름 목소리**로 바꿔 읽어요. 연결표는 그대로라 「지정한 그대로」로 언제든 되돌려요. 이름은 목소리 이름 · 괄호 앞 이름 · 괄호 안 영문 이름(예: `루시퍼 (Lucifer)`) · 다른 이름으로 맞춰요. 새 엔진에서 목소리를 불러오면 맞는 캐릭터가 있을 때 한 번 물어봐요.
- **목소리마다 모델**: 목소리 편집 › 모델에서 그 목소리만 쓸 모델을 고를 수 있어요 (예: 차분한 캐릭터만 다국어 v2). 「엔진 설정대로」면 엔진 카드의 모델이에요. 고른 모델은 목록 줄에 작게 보여요.
- **엑스트라 목소리** (캐릭터별 목소리 › 엑스트라, 기본 「자동」): 목소리를 정하지 않은 단역(카페 사장 · 편의점 점원 …)은 대사 분석이 알려 준 성별 · 나이로 그 엔진의 기본 목소리 가운데 맞는 것을 골라 읽어요. 같은 이름은 늘 같은 목소리이고, 엑스트라끼리는 되도록 다른 목소리예요. 「엑스트라 N명」을 펼쳐 자동으로 고른 목소리를 보고, 다른 목소리를 고르면 그 이름의 캐릭터 목소리로 고정돼요. 목소리 편집 › 엑스트라에서 남 · 여를 고른 목소리가 있으면 그것들 가운데서 골라요. 대사 분석이 꺼져 있거나 맞는 목소리가 없으면 전처럼 기본 목소리예요. 엔진의 기본 목소리 목록은 이 브라우저에만 저장해요.

## MiniMax 목록 JSON

‘목록 붙여넣기’에 아래와 같은 **JSON 배열**을 넣어요. `my_voice_id`를 본인이 사용할 수 있는 실제 ID로 바꾸세요. 다른 엔진은 ‘직접 추가’에서 엔진을 골라 등록해요.

```json
[
  {
    "voiceId": "my_voice_id",
    "name": "안내",
    "lang": "ko",
    "group": "내 목소리",
    "aliases": ["Guide"]
  }
]
```

- `voiceId`는 필수이며 `voice_id`도 받아요. `name`은 표시할 이름으로, 생략하면 ID를 사용해요.
- `lang`은 `ko`·`ja`·`en`·`zh` 또는 빈 값, `group`과 `aliases`는 선택 사항이에요.
- `model`에 해당 목소리의 생성 모델을 넣으면 MiniMax의 ‘목소리를 만든 모델’ 모드에서 사용할 수 있어요. 모르면 생략하세요.
- `autoGainDb`는 원본 음량 보정값을 알고 있을 때만 넣어요. 사용자가 정한 추가 음량 보정과 별도로 보관하며 ‘음량 고르게’를 켰을 때 중복 적용하지 않아요.
- 같은 ID를 다시 가져오면 목록의 이름·그룹·원어 등 제공된 항목을 갱신해요. 사용자 음량 슬라이더 값은 유지해요. API 키는 이 목록에 넣지 않아요.

## 읽기와 감정

**화자 찾기** (1.3.6, 대사 분석 안의 스위치, 기본 켬): 대사 색이나 이름표가 없어서 누구 말인지 알 수 없던 대사는 대사 분석이 서술과 앞뒤 대사를 보고 누구 말인지 골라요. 고를 수 있는 이름은 지금 캐릭터 · 나 · 목소리를 지정한 이름 · 그룹 멤버 · 이 채팅에서 배운 이름이고, 그 이름에 지정한 캐릭터별 목소리로 읽어요. 대사 색으로 이미 정해진 대사는 그대로예요. 대사 분석이 꺼져 있거나 엔진이 없으면 전처럼 메시지를 보낸 캐릭터 목소리예요.

대화문만, 서술 포함, 행동 제외, 전부 중에서 읽을 부분을 골라요. 캐릭터·나·내레이터의 목소리를 각각 연결할 수 있고, 대화 색이나 이름으로 화자를 찾을 수 있어요. 번역을 기다렸다가 읽기, 대사 소리 미리 만들기, 캐시 재사용, 음량 고르기, 대사 사이 쉼도 지원해요.

**읽기 → 본문과 제외할 내용**에서 상태창 등 읽지 않을 부분을 정해요. ‘건너뛸 태그’는 태그 안쪽 글까지 제외하고, ‘추가로 지울 글(정규식)’은 규칙에 일치한 부분만 제외해요. 태그 자체는 자동 정리하므로 정규식은 보통 비워 둬요. 태그만 지우는 규칙은 내용 제외나 감정 힌트를 방해할 수 있어요. 속마음은 **읽을 부분 → 직접 설정 → 속마음**에서 정해요.

새 사용자는 상태창·계획·미디어 태그와 코드 블록을 제외하고, `momentum`·`visuals`도 제외해요. 별도 태그가 없는 본문이나 `prose` 안의 내용은 읽어요. 기존 필터는 그대로 이어지며, **본문 필터 기본값** 버튼에서 설명을 확인한 뒤 원하는 경우에만 바꿀 수 있어요. 이 버튼은 정규식을 비우고 감정 태그 사용을 켜며, 읽을 부분·속마음·목소리·분석 연결·발음 사전은 유지해요.

PC와 모바일 모두 짧은 설정은 공간에 따라 두 칸으로 놓고, 긴 주소·JSON·정규식은 한 줄 너비를 사용해요. 좁은 화면이나 큰 글씨에서는 한 칸으로 바뀌어요. 발음 사전과 정규식은 고급 항목을 열어 설정할 수 있어요.

감정 분석은 **읽기 → 대사 분석**에서 따로 설정해요. 실리태번의 현재 연결, 실리태번에 저장한 공급자·모델, 별도의 OpenAI 호환 주소 중 하나를 고를 수 있어요. 분석 모델이 감정과 번역을 정하며 실제 목소리를 만드는 TTS 엔진은 엔진 탭의 설정을 사용해요. 감정 분석을 켰다고 모든 음성이 같은 강도로 감정을 표현하는 것은 아니에요.

감정 표현은 엔진·모델·목소리가 지원하는 범위에 따라 달라요. MiniMax 2.8 처럼 속삭임이 없는 모델은 속마음 · 속삭이는 대사만 같은 등급의 2.6 모델(hd → 2.6-hd, turbo → 2.6-turbo)로 읽어요. 분석이 ‘차분’이라고 한 대사는 감정을 따로 보내지 않고 엔진이 글을 보고 정하며, ‘외침’은 MiniMax 에서 화남으로 바꾸지 않고 음량만 키워요. **읽기 → 대사 분석 → 감정 세기**에서 약하게(감정을 따로 보내지 않고 엔진이 글을 보고 정함, 속삭임만 유지) · 보통 · 강하게(MiniMax speech-2.8 에서 감정에 맞춰 숨 · 웃음 · 한숨 · 헉 · 들이쉬는 소리를 줄 앞에 붙임)를 골라요. ElevenLabs 는 약하게면 안정감 1, 강하게면 감정이 붙은 줄의 안정감을 0.3 낮춰요 (1.3.8). 같은 곳의 **속마음**에서 속삭임 또는 일반(속삭이지 않고 엔진이 글을 보고 감정을 정함 — 대사 분석은 대사만 봐요)을 골라요. OpenAI의 일부 모델은 말투 지시를 받지 않고, OpenAI 호환 서버의 지시문 지원도 서버마다 달라요. Azure 스타일이나 ElevenLabs 태그 등도 지원 목소리·모델에서만 효과가 있어요. 브라우저 내장·Google 번역은 감정 파라미터를 지원하지 않아요.

**읽기 → 재생 → 재생 표시**에서 색깔만 / 색깔 + 밑줄 / 밑줄만을 고를 수 있어요. 재생 중 바로 반영되고, ‘읽는 대사 강조’를 끄면 표시하지 않아요. 원래 글꼴·색·서식은 유지해요.

내장 애드온을 끄면 재생·대기·미리 만들기를 중지하고 새 요청을 보내지 않아요. 서비스에 이미 도착한 요청의 처리나 요금까지 취소되는 것은 아니에요. 실리태번 현재 연결의 이미 전송된 분석은 본체가 별도 취소 신호를 받지 않아 응답 대기만 끝내고 늦은 결과를 사용하지 않아요.

## 저장되는 정보

API 키는 실리태번 설정에 저장되며 TTS 설정 내보내기에서 제외돼요. 음성 엔진에는 읽을 글이 전송되고, 감정 분석을 사용하면 선택한 분석 서비스에 대사·화자 이름·주변 서술·번역문 일부가 전송돼요. 분석 결과는 채팅에, 만든 음성은 이 브라우저의 캐시에 저장돼요. 데이터 탭에서 캐시를 비울 수 있어요.

설정 가져오기는 API 키를 가져오지 않으며, 키가 있는 엔진의 서버 주소를 임의로 바꾸지 않아요. 직접 입력한 주소가 다른 서버를 가리키는지 저장 전에 확인하세요.
