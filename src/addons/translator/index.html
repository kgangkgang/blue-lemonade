번역 v2.1.6

원하는 LLM으로 채팅을 번역합니다

설정 프리셋

표시 방식
번역된 메시지에서 원문을 어떻게 함께 보여 줄지 고릅니다.
새 메시지가 올라오면 자동으로 번역할 대상을 고릅니다.
텍스트 보호
이 패턴과 일치하는 텍스트는 번역하지 않고 원문 그대로 둡니다. 한 줄에 하나씩 입력하며 프리셋에 함께 저장됩니다.
이 패턴이 들어 있는 줄은 '접기 방식'에서도 항상 펼쳐 둡니다. 코드 블록이나 강조 구문 등에 쓰세요.
번역 동작
긴 답변은 문단별로 번역해요. 중단되면 같은 설정으로 다시 눌러 이어갈 수 있어요. 진행분은 이 브라우저에 하루 동안 보관돼요. 한글 번역문을 선택하고 언어 버튼을 누르면 대응 원문으로 해당 문단을 다시 번역해요. 확인 후 교체·되돌릴 수 있어요.
보내기 번역
입력창 옆 💬 버튼으로도 켜고 끕니다. 켜면 내가 보내는 글이 아래 언어로 번역돼 AI 에게 가고, 내 화면에는 입력한 글이 그대로 보여요. 💬 를 길게 누르면 입력창의 글을 지금 바로 번역합니다.
둘을 다르게 하면 "서술은 영어, 대사는 일본어" 같은 이중 언어 프리셋과 똑같은 꼴로 보내요.
"다시 번역"은 보낸 번역문을 채팅 번역 프롬프트로 되돌려 보여 줘요 — AI 답변과 같은 번역체라 나중에 읽어도 말투가 이어져요. 번역이 한 번 더 도니 시간 · 토큰이 두 배.
이름 · 용어 · 말투를 맞추라고 번역 요청에 같이 넣습니다 (번역되진 않음). 넣을수록 토큰이 늘고 조금 느려져요.
최근 대화 개수는 프롬프트 탭의 {{llmContext}} 메시지 수를 따릅니다. 번역 지시문은 프롬프트 탭 › ⚙️ 보내기 번역 프롬프트에서 고쳐요 ({{targetLang}} = 위 언어).
메시지 아이콘
체크한 아이콘은 메시지 메뉴에서 숨깁니다.
연결 방식

실리태번에서 지금 선택한 API·모델·접속 설정을 그대로 사용해요. 모델을 바꾸면 다음 번역부터 따라가요.

0이면 현재 연결의 응답 길이 설정을 따라가요.
공급자 · 모델
💡 주소를 넣고 '모델 목록 불러오기'를 누르면 그 서버가 제공하는 모델이 아래 목록에 뜹니다. 받은 목록은 저장되며, 설정을 열었을 때 목록이 비어 있으면 저장된 주소로 자동으로 받아옵니다.
💡 비워두면 SillyTavern 본체의 Custom (OpenAI-compatible) 접속 설정(주소/추가 헤더/Body)을 그대로 사용합니다.
🔑 API 키는 본체의 Custom (OpenAI-compatible) 키를 공유합니다. (키가 필요 없는 로컬 서버는 비워두셔도 됩니다.)
API 키는 SillyTavern 본체의 API 연결 설정에 저장된 키를 씁니다. 목록에 없는 모델은 맨 아래 '커스텀 모델 입력'으로 넣으세요.

프롬프트
💡 채팅 번역 프롬프트 또는 커스텀 프롬프트를 선택하면 메시지 번역 시 적용됩니다.
⚙️ 유틸리티 프롬프트(재번역, 입력 번역, 프리필)는 수정만 가능하며 선택시 메시지 번역에는 채팅 번역 프롬프트가 사용됩니다.
규칙 프롬프트 (채팅별)
현재 채팅에만 적용되는 번역 규칙입니다. 다른 채팅으로 옮기면 그 채팅의 규칙으로 바뀝니다.
용어집
이름·호칭·고유명사를 정해 둔 번역으로 고정해요. 원문에 그 말이 있을 때만 프롬프트에 들어가요. 번역을 쉼표로 여러 개 적으면 (길드, 조합, 상인회) 맥락에 맞는 것을 골라 쓰고, 원문도 쉼표로 여러 표기를 적을 수 있어요 (Guild, Merchant Guild).
프리필 · 문맥
프롬프트 목록의 ⚙️ 프리필 내용을 AI 응답 앞에 미리 채워서 보냅니다.
💡 프롬프트에 {{llmContext}}를 입력하면 최근 메시지들이 자동으로 삽입됩니다.
⚙️ "마지막 메시지 제외"는 채팅 번역에만 적용됩니다 (번역 대상과 중복 방지).
전체 번역
채팅 전체를 번역할 때 메시지 사이에 기다릴 시간입니다. API 호출 한도에 걸리면 늘려 주세요.
