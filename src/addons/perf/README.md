# 요청 로그의 공식 가격 안내

Blue Lemonade → 확장 → 성능 보조 → 요청 로그에서 **현재 연결 가격**을 확인하세요.
필요하면 성능 보조의 요청 로그를 불러오도록 켜고 새로고침하세요.

1. 실리태번에서 사용할 API와 모델을 고릅니다.
2. 현재 연결 가격에서 제공처·모델·통화와 확인 날짜를 봅니다.
3. 단가를 펼치면 입력·출력·캐시 비용과 공식 출처를 볼 수 있습니다.
4. **자동 확인**을 켜 두면 앱을 사용하는 동안 하루에 한 번 가격표를 받습니다.
   **지금 확인**은 수동으로 새 가격표를 받으며, 1분 안에 여러 번 조회하지 않습니다.

공식 자료는 서버 작업이 매일 한국 시간 12:17에 확인합니다. GitHub 사정으로 실행이
늦어질 수 있으므로 화면의 제공처별 확인 날짜가 기준입니다. 가격표만 내려받으며
API 키·대화·선택한 모델이나 계정 정보는 가격표 서버로 보내지 않습니다.

## 어느 가격을 보여주나요?

실제 요청을 보낸 제공처의 공식 가격을 사용합니다. Claude·OpenAI·DeepSeek뿐 아니라
Gemini·Mistral·xAI·Groq·OpenRouter 등 등록된 제공처를 구분합니다. USD·CNY·Pollen·credit은
섞지 않으며, 지원되는 캐시 유지 시간·긴 문맥·처리 등급·지역·시간대 조건을 적용합니다.
응답에 실제 비용이 포함되는 지원 제공처는 그 값을 우선합니다.

29개 종량제 제공처의 공식 자료를 확인합니다. 이 중 26개는 검토된 가격표 형식의 금액
변경을 읽고, Vertex·Cohere·AI21은 공식 원문이 달라지면 검토가 필요하다고 표시합니다.
모든 모델·계약·부가 기능의 가격을 보장하지 않습니다. 구독형·직접 운영·배포형 비용은
종량제와 따로 안내하며, 모델이나 과금 조건을 확인할 수 없으면 미확인으로 남깁니다.

## 갱신이 안 될 때

네트워크 오류·가격표 형식 변경·모델 누락·큰 금액 변화가 있으면 그 제공처의 마지막
정상 가격과 확인 날짜를 유지합니다. 나머지 제공처는 정상적으로 갱신할 수 있습니다.
실패한 다운로드는 간격을 늘려 다시 시도하며, 오프라인에서도 저장된 가격을 보여줍니다.
상태가 오래되거나 검토 필요라면 단가 옆 공식 출처에서 최신 조건을 확인하세요.

새 가격은 다음 요청부터 적용합니다. **이미 진행 중인 요청과 저장된 과거 기록의 비용은
다시 계산하지 않습니다.** 실리태번이 사용량을 전달하지 않는 응답은 토큰 수가 추정일 수
있고, 할인·세금·도구/미디어 비용 등은 빠질 수 있으므로 실제 청구 내역과는 다릅니다.
