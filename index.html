5.9.2 · 내장 도구

전부 켤 필요는 없어요.

화면만 꾸며도 좋고, 쓰던 테마에 도구만 더해도 좋아요.

테마 사용내장 확장 사용

화면도, 도구도 함께.

블루레몬에이드의 색과 글꼴을 적용하고, 필요한 내장 확장을 따로 켜서 사용해요.

설정 위치 Blue Lemonade › 테마 › 기타 설정 › 사용 모드

위 버튼은 사용 방식 안내예요. 실제 모드는 실리태번에서 바꿔 주세요.

목소리로 듣고 싶어요 (TTS)
  1. 확장 › TTS를 켜고 실리태번을 새로고침하세요. TTS 버전 표시를 누르면 자세한 사용법이 열려요. 실리태번 확장 탭에서도 TTS 설정을 바로 열 수 있고, 표시할 위치 › 확장 탭에 TTS 설정 표시에서 숨기거나 다시 표시할 수 있어요.
  2. 엔진에서 음성 서비스를 고르고 본인의 API 키와 모델을 입력하세요. 브라우저 내장 음성은 키 없이 사용할 수 있어요.
  3. 목소리에서 계정 목록을 불러오거나 직접 등록하고, 기본 목소리와 캐릭터별 목소리를 연결하세요.
  4. 먼저 대사를 눌러 한 문장을 들어 보세요. 익숙해지면 읽기에서 자동 읽기·읽을 부분·재생 표시를 조절하고, 필요할 때 감정 분석 API를 따로 연결하세요.

새 설정은 자동 읽기·미리 만들기·감정 분석이 꺼져 있어요. 기존 설정은 유지하며, 원할 때만 본문 필터 기본값 버튼으로 필터를 새 기본값에 맞추세요.

각 서비스의 요금과 지원 목소리는 계정에 따라 달라요. 기존 TTS 단독 확장을 쓰고 있다면 끄고 새로고침하세요.

도구별 화면과 사용법 보기 · 원본 안내: Character Assets · LLM Translator Custom · Prompt Panel

메뉴와 자료를 한글로 보고 싶어요
  1. 블루레몬에이드의 확장 › 한글화 패널을 켜고 새로고침하세요.
  2. 한글화 탭에서는 실리태번·헬퍼·데우스·샤진을 API 없이 한글로 표시해요.
  3. 자료를 번역하려면 설정 › 연결에서 현재 연결 따라가기 또는 직접 연결을 고르세요. LLM 번역 설정도 가져올 수 있어요.
  4. 프리셋·월드인포·봇카드·정규식 중 필요한 탭을 열고 항목을 선택해 번역하세요. API 번역에는 사용 중인 공급자의 요금이 적용돼요.
  5. 패널의 버전 버튼에 자세한 사용방법이 있어요. 익숙해지면 보조 설명을 숨길 수 있어요.

기존 단독 Prompt Panel·LLM 번역·CustomThemeStyleInputs를 사용 중이라면 같은 기능의 내장판과 동시에 켜지 마세요.

버벅일 때, 여기부터 확인해요

Blue Lemonade 설정에서 하나씩 바꾸고 같은 채팅을 다시 열어 비교해 보세요.

  1. 확장에서 쓰지 않는 기능을 끄고 새로고침해요. 확장 › 성능 보조의 설정 창에서는 안 쓰는 탭의 이 도구 불러오기도 끌 수 있어요. 바꾼 뒤 새로고침해야 적용돼요. 메뉴에서 숨기는 것과는 달라요.
  2. 움직이는 글이나 배경에서 끊기면 프롬프트 › 데우스 엑스 마키나 › 감정 대사 효과 › 효과 살리기를 꺼서 비교해요. 날씨는 채팅 › 화면 › 날씨 › 채팅 뒤 효과에서 끔을 골라 비교할 수 있어요.
  3. 답변이 한 글자씩 나올 때 버벅이고 실리태번 페이드 인을 쓰고 있다면, 채팅 › 화면 › 가벼운 페이드 인을 켠 뒤 아래 나타나는 실리태번 페이드 인을 꺼서 바꿔 보세요.
  4. 계속 느리면 채팅 › 기타 › 진단 복사와 함께, 느린 동작이 채팅 열기·스크롤·답변 표시 중 무엇인지 알려 주세요. 첫 답변이 오기 전 대기는 연결이나 모델의 응답 시간일 수도 있어요.

기기와 채팅의 길이, 그림·효과·켜 둔 확장에 따라 차이가 있어요. 원래 값을 기억해 두고 효과가 없는 변경은 돌려놓으세요.

설정은 어디에서 여나요?

실리태번의 확장 탭 › Blue Lemonade 또는 입력창 옆 요술봉 › Blue Lemonade에서 열어요. 색은 테마 › 색, 글꼴은 글자 › 본문에서 바꿔요.

번역과 목소리도 바로 쓸 수 있나요?

내장 도구는 필요한 것만 켜세요. AI 번역이나 외부 음성 서비스를 쓰려면 해당 서비스의 연결 설정이 필요하고, 이용 요금이 생길 수 있어요. 브라우저 내장 음성은 API 키 없이 쓸 수 있어요.

업데이트는 어떻게 하나요?

저장소 주소로 설치했다면 Blue Lemonade › 테마 › 업데이트에서 확인해요. ZIP으로 설치했다면 새 ZIP을 같은 폴더에 덮어써 주세요.

LLM 번역

읽는 글과 보내는 글을 원하는 언어로 바꿔요.＋

이럴 때 써요한국어로 입력해 AI에게는 영어로 보내고, 내 화면에서는 한국어 그대로 읽고 싶을 때.

여는 곳Blue Lemonade › 확장 › LLM 번역

처음 사용하는 순서

  1. 기능을 켜고 새로고침해요. 모바일에서는 세부 설정을 눌러 번역 설정 창을 열어요.
  2. 모델 탭에서 번역에 쓸 현재 연결 또는 직접 연결을 준비해요. 채팅 연결과 다른 모델을 쓸 수도 있어요.
  3. 먼저 메시지 하나로 번역 결과를 확인해요. 입력만 번역하려면 요술봉의 입력 번역을, 앞으로의 답변을 계속 번역하려면 번역 › 자동 번역 모드를 골라요.
  4. 번역 › 보내기 번역에서 서술 언어, 대사 언어, 내 화면에 보일 글을 정해요. 입력창 옆 말풍선 버튼으로도 켜고 끌 수 있어요.

옵션과 활용법

자동 번역
새로 올라오는 메시지 중 AI만, 유저만, 둘 다를 고릅니다. 예전 채팅 전체를 번역하는 동작과 달라요.
원문과 번역문 함께 보기
번역된 메시지에서 원문을 접거나 펼쳐 함께 봅니다. 이 선택은 보내는 언어를 바꾸지 않아요.
서술 언어 / 대사 언어
서술은 English, 따옴표 안 대사는 Japanese처럼 나눌 수 있어요. 대사 언어를 비워 두면 별도의 언어 지정을 하지 않아요.
내 화면에 보일 글
입력한 원문, AI에게 보낸 번역문, 보낸 글을 다시 한국어로 번역한 글 중 고릅니다. 마지막 선택은 추가 번역 요청이 발생해요.
참고 정보
캐릭터 설정·페르소나·월드인포·작가 노트·최근 대화를 번역에 참고하게 할 수 있어요. 이름과 말투를 맞추는 데 쓰며, 많이 넣을수록 요청 길이가 늘어요.
용어집
이름과 고유명사의 번역 표기를 맞춥니다. 번역문이나 월드인포에서 후보를 뽑고, 보내기 번역에도 쓸지 정할 수 있어요. 결과를 확인하고 다듬어 주세요.
선택 부분 재번역
기능을 켠 뒤 번역문 일부를 골라 언어 버튼을 누르면 대응 원문으로 해당 문단을 다시 번역해요. 결과를 확인해 교체하고 되돌릴 수 있어요.
텍스트 보호 / 접기 금지
보호할 패턴은 번역에서 제외하고, 접기 금지 패턴은 접기 보기에서도 펼칩니다. 코드·상태창처럼 그대로 남겨야 하는 내용을 다룰 때 써요.
긴 번역 이어하기
문단별 번역 중 중단되면 같은 설정으로 다시 눌러 이어갈 수 있어요. 진행분은 해당 브라우저에 하루 동안 보관됩니다.
프리셋과 프롬프트

채팅 캡처

남길 대화만 골라 이미지·영상·움짤로 만들어요.＋

이럴 때 써요좋아하는 장면을 예쁘게 저장하거나 이름을 가려 다른 사람에게 보여 주고 싶을 때.

여는 곳Blue Lemonade › 확장 › 채팅 캡처

처음 사용하는 순서

  1. 기능을 켜고 저장할 메시지를 선택해요. 더 오래된 장면은 이전 채팅 불러오기로 목록에 추가해요.
  2. 캡처 미리보기 만들기를 눌러 선택한 장면을 확인해요.
  3. 저장 방식에서 파일 종류와 표시할 항목을 고르고 필요하면 캡처용 글 편집·이름 가림을 설정해요.
  4. 파일 만들기가 끝나면 저장 링크로 받아요. 설정을 바꾼 뒤에는 파일을 다시 만들어야 새 설정이 들어가요.

옵션과 활용법

파일 종류
정지 화면은 PNG, 움직임은 영상(MP4/WebM)이나 GIF·APNG·WebP를 골라요. 실제 가능한 영상 형식은 브라우저 지원에 따라 달라질 수 있어요.
캡처 프리셋
가벼운 움짤·선명한 움짤·고화질 영상·PNG 등 준비된 설정을 고르거나 지금 설정을 저장해요.
빠른 미리보기
구도와 내용을 먼저 보는 용도예요. 빠른 미리보기 자체는 최종 저장 파일이 아니므로 파일 만들기를 눌러 주세요.
표시할 항목
본문만 남길지, 이름·프로필 등 정보를 같이 넣을지 고릅니다. 필요한 항목만 직접 선택할 수도 있어요.
날씨와 필터
날씨 효과를 포함하고 그레인·흑백·색감 등을 조절할 수 있어요. 움직이는 효과는 영상·움짤로 확인해요.
캡처용 글 편집
저장할 화면에서만 글을 다듬습니다. 실제 채팅의 원문·번역문은 바뀌지 않아요.
로그 공유·이름 가림
공유할 장면의 이름과 표현을 가릴 때 써요. 최종 파일에 남은 본문·이미지도 직접 확인해 주세요.
원문 / 번역본 목록
메시지를 고르는 목록의 표시 언어를 바꿉니다. 번역이 없는 메시지는 원문으로 보여요.

긴 대화를 고해상도 영상으로 만들면 시간과 메모리를 많이 쓸 수 있어요. 모바일에서는 짧은 장면·가벼운 형식부터 시작해 보세요.

단어 치환

선택한 채팅에서 이름이나 표현을 한꺼번에 바꿔요.＋

이럴 때 써요이름 표기를 통일하거나 같은 대화 속 낱말을 여러 곳에서 고칠 때.

여는 곳Blue Lemonade › 확장 › 단어 치환

처음 사용하는 순서

  1. 바꿀 메시지를 골라요. 목록에 없는 이전 메시지는 더 불러와요.
  2. 찾을 말과 바꿀 말을 적어요. 레몬, lemon → 귤처럼 여러 표기를 쉼표로 묶을 수 있어요.
  3. 대소문자·낱말 단위·조사 보정 옵션을 고르고 전후 보기에서 바뀔 부분을 읽어요.
  4. 원하는 결과일 때 적용해요. 채팅 적용과 입력해 둔 작업 글의 치환을 구분해요.

옵션과 활용법

대소문자 구분
켜면 lemon만 찾고 Lemon은 남겨요. 끄면 대소문자를 구분하지 않아요.
낱말 단위
켜면 사과를 찾되 사과나무 속 글자까지 바꾸지 않아요. 조사 보정과 함께 쓰면 사과는처럼 조사가 붙은 말도 찾아요.
조사 자동 보정
사과 → 귤로 바꿀 때 사과는 → 귤은, 사과를 → 귤을처럼 받침에 맞게 조사도 조절해요.
규칙과 프리셋
여러 규칙을 추가하고 각각 켜고 끕니다. 반복해 쓰는 규칙은 프리셋으로 저장해 불러와요.
번역문
원문과 번역문을 구분해 확인해요. 전후 보기에서 어느 쪽이 바뀌는지 살펴본 뒤 적용하세요.
되돌리기
작업 중 제공되는 되돌리기로 직전 치환을 복원할 수 있어요. 중요한 채팅은 일괄 적용 전에 별도 백업을 남겨 두면 좋아요.

단어 치환은 내가 정한 글자를 바꾸는 도구예요. 뜻을 이해해 문장을 다시 쓰게 하려면 다시 쓰기, 언어를 바꾸려면 LLM 번역을 사용해요.

07글·이야기

다시 쓰기

원하지 않는 묘사가 나온 문장만 AI에게 다시 쓰게 해요.＋

이럴 때 써요특정 버릇이나 묘사가 반복되지만 답변의 나머지 내용은 마음에 들 때.

여는 곳Blue Lemonade › 확장 › 다시 쓰기

처음 사용하는 순서

  1. 기능을 켜고 새로고침한 뒤 연결에서 현재 채팅 연결 또는 별도의 모델을 골라요.
  2. 금지 묘사에 찾을 표현과 고칠 방향을 정해요. 처음에는 분명한 규칙 하나로 확인해요.
  3. 특정 캐릭터에게만 적용할 규칙이나 원래 그 특징을 가진 캐릭터의 예외를 넣어요.
  4. 새 답변이 끝나면 규칙에 걸린 문장을 고칩니다. 결과와 요청 기록을 보고 범위를 다듬어요.

옵션과 활용법

찾기와 고쳐 쓰기
금지 표현을 찾는 단계는 기기 안에서 처리해요. 걸린 문장이 있을 때만 그 문장을 AI에게 보내고 나머지 글은 유지해요.
규칙 작성
단어 목록뿐 아니라 어떤 묘사인지 설명해야 해요. 규칙 만들기용 안내를 복사해 AI에게 작성시키고, 받은 JSON을 검사해 넣는 방식도 지원해요.
이름 한정 / 예외
모든 캐릭터에 일괄 적용하거나 특정 이름에 한정해요. 예외에는 허용할 규칙을 골라 넣습니다. 누구의 묘사인지는 고치는 모델의 판단도 필요해요.
반복 감지
최근 AI 답변과 거의 같은 문장을 찾아 그 문장만 다시 쓰게 해요. 비교할 최근 답변 수, 유사도 기준, 너무 짧은 문장을 제외할 최소 길이를 조절할 수 있어요.
글 선택 시 단어 밴
채팅에서 고른 표현으로 금지 규칙을 빠르게 만들 때 써요. 버튼 표시를 꺼도 기존 규칙과 다시 쓰기는 유지돼요.
마지막 답변 검사 / 테스트
마지막 AI 답변을 수동으로 검사하거나 테스트 칸에 글을 넣어 어떤 표현이 잡히는지 확인할 수 있어요. 실제 고쳐 쓰기를 실행하면 모델 요청이 생겨요.
고급 설정
응답 제한 시간·최대 시도·최근 메시지를 돌아볼 범위를 정해요. 실패가 반복되면 규칙을 좁히거나 모델 연결을 확인해요.
실패하거나 중단하면
최대 시도까지 고치지 못하면 원래 문장을 남겨요. 고치기는 번역 전에 진행되어 같은 답변을 불필요하게 두 번 번역하지 않게 해요.
씬 플랜 검사
해당 장면 계획 형식을 쓰는 프리셋에서 계획 누락·잘린 답변을 확인하는 별도 기능이에요. 일반 금지 문장 수정과 달리 답변 전체를 다시 생성할 수 있어요.
비용 구분
단어 검사 자체에는 API 비용이 없지만 고쳐 쓰기는 모델 요청이에요. 전체 답변 다시 받기는 답변 하나를 새로 생성하는 비용이 들어요.

씬 플랜 기능은 해당 형식의 프리셋을 쓸 때 설정하세요. 고급 동작과 규칙 예시는 세부 설정의 버전 버튼에 있는 도움말에서도 확인할 수 있어요.

전개 지시

다음 장면의 방향을 채팅 요청에 덧붙여요.＋

이럴 때 써요등장인물을 만나게 하거나 장면을 천천히 진행하도록 잠깐 방향을 정하고 싶을 때.

여는 곳Blue Lemonade › 확장 › 전개 지시

처음 사용하는 순서

  1. 기능을 켜고 입력창 옆 깃털을 눌러요.
  2. 원하는 전개를 적고 켜짐 스위치를 켜요. 깃털을 길게 눌러도 켜고 끌 수 있어요.
  3. 이후 대화를 보내면 적어 둔 지시가 함께 들어갑니다.
  4. 원하는 장면이 끝나면 끄거나 내용을 고쳐요. 꺼도 적어 둔 내용은 남아요.

옵션과 활용법

전개 지시
다음 대화 요청부터 이야기 방향을 넣습니다. 한 번만 보내고 저절로 꺼지는 기능은 아니에요.
항상 지시
창을 옆으로 넘기거나 제목을 눌러 전환해요. 여기에 적은 내용은 별도의 틀 없이 그대로 매번 들어가요. 켜져 있으면 깃털이 그라데이션으로 보여요.
저장 / 최근
책갈피의 저장에는 자주 쓸 지시를 모으고, 최근에는 실제로 보낸 지시가 쌓여요. 누르면 입력칸으로 불러옵니다.
삽입 위치
0은 프롬프트 맨 끝, 1은 마지막 메시지 앞이에요. 전개 지시와 항상 지시는 같은 위치에 들어갑니다.
프롬프트 틀
설정의 {{direction}} 자리에 내가 쓴 전개 지시가 들어가요. 틀을 바꿀 때 이 자리를 남겨 주세요.
입력창 버튼
버튼 표시를 끄면 버튼과 지시 삽입이 함께 꺼져요. 단순히 아이콘만 숨기는 옵션으로 생각하지 않도록 주의해 주세요.

별도 모델을 호출하는 도구는 아니며 현재 채팅 요청에 지시가 추가돼요. 지시가 반영되는 정도는 프리셋과 모델에 따라 달라질 수 있어요.

09그림·꾸미기

캐릭터 에셋

캐릭터의 표정·장면 그림을 모아 답변 안에 표시해요.＋

이럴 때 써요AI가 웃거나 놀라는 장면에서 준비한 그림이 함께 나오게 하고 싶을 때.

여는 곳Blue Lemonade › 확장 › 캐릭터 에셋

처음 사용하는 순서

  1. 캐릭터를 열고 이미지 또는 ZIP으로 그림을 올려요. 파일 이름이 그림을 부르는 키워드가 됩니다.
  2. 프리셋·캐릭터 카드·작가 노트 중 사용할 곳에 {{img_inprompt}}를 넣어요. 그림 규칙과 켜진 그림 목록이 AI에게 전달됩니다.
  3. AI가 {{img::Name_smile.png}}처럼 출력하면 그 자리에 그림이 나타나요.
  4. 목록에서 그림을 눌러 크게 보고 이름·켜짐 상태를 관리해요. 프리셋 폴더로 그림 묶음도 나눌 수 있어요.

옵션과 활용법

파일 이름
Name_smile.png의 키워드는 Name_smile이에요. 그림 이름과 AI에게 알려 준 이름이 맞아야 해요.
프리셋 폴더
같은 키워드의 그림을 여러 폴더에 두고 묶음별로 켜고 꺼요. 여러 폴더가 켜져 있으면 위쪽 폴더의 그림이 우선해요.
다른 카드에서 불러오기
같은 캐릭터의 다른 카드에서 기존 폴더를 연결해 쓸 수 있어요. 파일은 한곳에 두고 카드별 켜짐 상태를 따로 정해요.
번호 묶음
Name_smile.png와 Name_smile-1.png처럼 번호만 다른 파일을 하나의 키워드로 묶고 그중 하나를 보여 줄 수 있어요.
채팅에 그림 표시
이 확장이 img 태그를 그림으로 바꿀지 정해요. 이미 정규식이 그림을 만드는 경우에는 표시 기능이 겹치지 않게 확인해요.
목록만 넣기
{{img_keywords_autogen}}은 그림 목록만 넣어요. 규칙을 직접 쓸 때 사용합니다. {{charkey}}는 캐릭터 폴더 이름이에요.
여러 장 관리
이름 검색·여러 장 선택·한꺼번에 켜기/끄기·폴더 이동을 지원해요. 끄기는 파일을 남기지만 지우기는 파일을 삭제해요.
그림 가볍게 만들기
변환 크기를 확인한 뒤 더 작아지는 정지 이미지를 WebP로 교체해요. 움직이는 그림은 보존해요. 바뀐 파일의 원본이 필요하면 먼저 따로 보관해 주세요.

그림을 올리는 것만으로 AI가 반드시 출력하지는 않아요. 매크로가 실제 요청에 들어가는지와 그림 이름을 먼저 확인하세요. ZIP에 같은 이름이 있으면 기존 그림을 덮어쓸 수 있어요.

한글화 패널

외국어 프리셋·월드인포·캐릭터 카드를 읽고 번역해요.＋

이럴 때 써요프리셋 토글이 무슨 역할인지 알고 필요한 지시문만 이해하고 싶을 때.

여는 곳Blue Lemonade › 확장 › 한글화 패널

처음 사용하는 순서

  1. 패널에서 프리셋·월드인포·봇카드 중 읽을 자료 종류를 골라 불러와요.
  2. 먼저 제목과 내용을 읽거나 검색해요. 한글화 사전으로 바꾸는 UI 이름은 API 없이 볼 수 있어요.
  3. 본문을 번역하려면 설정 › 연결에서 연결을 준비하고 번역할 항목을 체크해요.
  4. 제목·본문·주석 중 필요한 번역을 실행해 결과를 읽어요. 읽기만 할 때는 원본에 적용을 누를 필요가 없어요.

옵션과 활용법

선택 체크

캡처에만 단어 치환을 적용하거나 여러 이름을 가려요. 네모·모자이크·테이프마다 색·여백·외곽선·그림자를 따로 저장해요. 원문과 번역문은 바뀌지 않아요.

PNG는 최대 3배·16MP, 영상은 3~30초·너비 최대 1080px 또는 1440px·30fps로 저장해요. 자동 스크롤 없이 고정 화면으로 저장해요. 파일당 최대 문단 수를 1~20개로 정하고, 화면을 넘는 긴 문단은 줄 사이에서 더 나눠요. 각 파일을 미리 보거나 전체 ZIP으로 저장해요. GIF는 최대 720px·10fps·256색이에요. 재생 중인 배경과 날씨를 담고 테마색 비율로 가독성을 조절해요. 원본 대화나 재생 시간 설정을 바꾸지 않으며, 소리는 포함하지 않아요.

영상과 움짤에는 채팅에서 돌던 글자 움직임(데우스 감정 대사의 흔들림 · 빛 · 색 흐름)도 함께 담겨요.

움짤은 GIF · APNG(색 그대로) · WebP(가볍게) 중에 고르고, APNG · WebP 는 최대 용량(MB)을 정하면 한도에 맞춰 저장해요. 미리보기 아래에 파일 용량이 나와요.

캡처 창을 열면 빠른 미리보기로 첫 화면부터 보고, 저장할 파일은 ‘파일 만들기’를 누를 때만 만들어요. 8MB 움짤 · 선명한 움짤 · 고화질 영상 · 이미지 프리셋이 들어 있고 내 프리셋도 12개까지 저장해요. 글 편집은 문단마다 한 줄 + 체크박스라, 고른 문단만 남기거나 한 번에 지워요.

Blue Lemonade를 켠 상태에서 채팅 입력칸에 아래 명령을 한 줄씩 적어 보세요. 입력칸 위에 표시되는 실행 버튼을 누르면 바로 처리돼요. 보내기 버튼도 사용할 수 있고, Enter 전송을 켜 두었다면 Enter로 실행할 수 있어요.

원하는 메시지로 이동
/240번 채팅으로 가기 또는 /240 — 화면에 표시된 #240 메시지로 이동해요. 번호는 #0부터 시작해요. 현재 대화에 없는 번호면 가능한 범위를 알려줘요.
처음이나 마지막으로 이동
/맨 위로 · /맨 아래로 — 오래된 메시지가 화면에 접혀 있어도 해당 위치로 찾아가요.
대화에서 말 찾기
/대화 검색 약속 — 현재 대화의 메시지에서 ‘약속’을 찾아요. 검색어를 원하는 말로 바꾸세요. 같은 명령이나 입력칸 위 버튼을 다시 실행하면 다음 결과로 이동하고, 마지막 결과 뒤에는 처음으로 돌아와요.
답변 생성 멈추기
/생성 중지 — 지금 작성 중인 답변을 멈춰요. 생성 중인 답변이 없으면 상태를 알려줘요.
예시 다시 보기
/ 또는 /도움말만 입력하면 입력칸 위에 지원하는 표현이 보여요. 명령을 외우지 않아도 여기서 다시 확인할 수 있어요.
작은 오타가 있어도
/240번 체팅으로 가기, /아레로, /도음말, /대화 검샥 약속처럼 지원하는 명령의 작은 오타는 뜻이 하나로 정해지면 알아들어요. 입력칸 위의 해석이 원하는 동작인지 보고 실행하세요. 여러 뜻으로 읽히면 실행하지 않고 다시 입력하도록 안내해요. 메시지 번호와 찾을 말은 임의로 고치지 않아요.
