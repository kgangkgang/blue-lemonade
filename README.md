# 블루 레몬에이드 · Blue Lemonade 2.7.9 (예전 이름: Salty · 소금)

드림주 전용 실리태번 테마 확장. 다른 테마 확장 없이 이것 하나로 동작함. 폴더 이름과 저장된 설정 키는 예전 그대로 `salty` (그래서 업데이트해도 설정이 이어짐).
읽기 편한 글자, 선 없는 화면, 한곳에서 고치는 글꼴·색.

## 설치 (폰)

1. zip을 `SillyTavern/data/default-user/extensions/` 에 풀기
   → `extensions/blue-lemonade/manifest.json` 이 되어야 함
2. 실리태번 새로고침
3. 확장 → **블루 레몬에이드** 를 열면 맨 위 "설정 점검"이 보임. 뜨는 버튼만 누르면 됨
   - Moonlit Echoes / Moonlit Slate / 폰트 매니저 끄기 (이 테마와 겹치면 모양·글꼴이 섞임)
   - 사용자 설정 → 커스텀 CSS 에 남은 예전 테마 비우기
   - 메시지 스타일을 플랫으로

업데이트할 때는 `extensions/blue-lemonade` 폴더를 지우고 새 zip을 푸세요. 설정은 남아요.

## 2.7.8 에서 바뀐 것

- 에셋 이미지: 투명 배경 캐릭터 컷도 이제 보통 그림과 **같은 모양 · 흐림 · 테두리**를 써요 (이미지 › 모양 › '투명 그림도 똑같이', 기본 켬). 끄면 예전처럼 자르지 않고 아래만 살짝 흐려지는데, 이때도 흐림을 끄면 아래가 녹지 않게 고침 (흐림을 껐는데 컷의 몸통이 점점 사라져 보이던 것).

## 2.7.7 에서 바뀐 것

## 2.5.3 에서 바뀐 것

- 폰 랙 줄이기 (탭 반응): 메시지의 ··· 메뉴를 열 때 style.css 가 `.mes:has(.extraMesButtons.visible)` 로 그 메시지를 알아내던 것을 스크립트가 붙이는 `.mes.bl-menu-open` 클래스로 바꿈. `:has()` 는 메뉴 하나 열 때 그 메시지 안 요소 전부(긴 답변이면 600개 넘음)를 다시 계산시켜서, PC 에서도 탭 한 번에 6ms(테마 없이 0.03ms)가 들었음 → 1.6ms. 스와이프 ‹ › 를 메뉴 밑으로 내리는 규칙도 `#chat:has(…)`(채팅 전체 다시 계산)에서 그 메시지만으로.
- 재 보니 탭이 느린 건 스크립트가 아니라(핸들러는 0.1ms) 스타일 계산이었음: 규칙 2,800개 중 어느 하나가 무거운 게 아니라 수백 개가 조금씩 쌓인 것. 다음 후보는 서랍 · 팝업용 규칙을 서랍이 열려 있을 때만 켜기(실험에서 −40%).

## 2.5.2 에서 바뀐 것

- 폰 랙 줄이기 (1단계 · 스크립트): 답변이 한 글자씩 자라는 동안 테마 스크립트 넷(숫자 쉼표 · 스크롤바 홈 · 프롬프트 목록 · 환영 화면)이 매번 깨어나 문서 전체를 다시 재던 것을 멈춤 — 채팅 본문 · 입력줄 안의 변화는 이제 무시. 스크롤바 홈 재기는 폰(≤1000px)에서 아예 안 돎(어차피 스크롤바를 숨김). 숫자 쉼표 1.5초 주기 점검은 서랍 · 팝업이 열려 있을 때만. 에셋 그림 줄바꿈 정리는 메시지마다 한 번만.
- 폰 랙 줄이기 (2단계 · CSS 일부): 설정창 미리보기 전용 규칙(`#salty-nochat` · `.salty-preview` · `.salty-sample`, 200개 남짓)은 설정 서랍을 펴거나 설정 팝업을 열 때까지 시트에서 빼 둠 (`src/lite.js`). 채팅이 바뀔 때마다 모든 규칙을 견주는데 이 규칙들은 설정창 밖에선 절대 맞지 않으면서 스타일 계산의 약 1/4 을 먹고 있었음. style.css 는 그대로.
- 잰 것 (PC · 폰 너비 412px · 366줄 채팅): 채팅 한 번 바뀔 때 테마 스타일 계산 5.9ms → 5.0ms (테마 없이는 0.7ms). 나머지 큰 몫은 서랍 · 팝업용 규칙 2천여 개가 채팅 요소에도 견줘지는 것 — 서랍이 열려 있을 때만 켜는 3단계(실험에서는 6.0 → 3.4ms)는 아직 안 함 (모양이 깨질 위험이 있어 따로 확인 필요).

## 어디서 고치나

확장 → 블루 레몬에이드, 또는 입력창 왼쪽 ✦ 메뉴 → **블루 레몬에이드 설정** (팝업으로 열림)

위에서 탭(대분류)을 고르고, 그 아래 칩(소분류)으로 한 묶음만 봐요. 고른 자리는 서랍과 팝업이 같이 기억해요.

### 글꼴 고르기

글꼴 탭 → 본문/대사/메뉴/속마음/강조 중 하나 → 언어 줄을 누르면 목록이 열림. 각 글꼴이 실제 모양으로 보이고, 위 찾기 칸으로 이름을 걸러요.
영어·일본어·중국어는 "한국어 글꼴 따라감"이 기본. 따로 고르면 그 언어 글자만 바뀌고 나머지는 한국어 글꼴이 맡아요.

목록 맨 아래에서 추가:
- **구글 폰트**: fonts.google.com 에 있는 이름 그대로 (예: `Gowun Batang`)
- **글꼴 파일**: 폰에 있는 ttf / otf / woff / woff2 를 올리면 실리태번 서버(user/files)에 저장돼서 계속 씀
- **CSS 링크**: 눈누 등에서 주는 CSS 주소 + font-family 이름

크기가 적힌 글꼴(예: 1.5MB)은 한 파일을 통째로 받는 글꼴이라 처음 한 번은 느릴 수 있어요.

## 알아둘 것

- 테마가 켜져 있으면 사용자 설정의 "Theme Colors" · Blur Strength 는 무시돼요. 색은 테마 탭 → 색 고치기에서.
- 밝은 테마에서는 에셋 이미지의 흰 배경이 종이색에 녹아들어요 (이미지 탭에서 끌 수 있음).
- 배경이 투명한 PNG는 자동으로 캐릭터만 보이게 표시돼요.
- 프리셋 카드(데우스 등)의 가는 테두리는 없애고 옅은 면으로 바꿔요. 왼쪽 색 띠는 그대로.
