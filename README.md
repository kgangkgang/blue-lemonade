# 블루 레몬에이드 · Blue Lemonade 3.9.2

전용 실리태번 테마 확장. 다른 테마 확장 없이 이것 하나로 동작함. 
읽기 편한 글자, 선 없는 화면, 한곳에서 고치는 글꼴·색.

[화면 둘러보기 · 업데이트 · 모바일 ZIP](https://kgangkgang.github.io/blue-lemonade/)

## 3.9.2

- 되돌리기·다시 실행 알림의 닫기 ×를 없앴어요. 알림을 누르면 바로 닫히고, 시간이 지나면 자동으로 사라져요.

## 3.9.1

- 스타일을 저장하거나 캐릭터별 스타일을 바꿀 때 화이트·나이트 배경 테마색 농도도 함께 보존해요. 예전에 저장한 스타일에 농도가 없으면 현재 값을 유지해요.
- 업데이트 전 설정 보존, 긴 채팅, 배포 파일 일치 검사를 추가했어요. 검사 도구는 테마 실행 파일에 포함되지 않아요.

## 3.9.0

- 대사 형광펜에 끝이 둥근 알약 모양을 추가했어요. 굵기와 위치를 조절하고 펜 자국·직사각형으로도 바꿀 수 있어요.
- 모바일 슬라이더는 손가락을 가로로 밀 때만 조절돼요. 세로 스크롤이나 가벼운 터치로 값이 바뀌지 않게 했어요.
- 바꾼 설정 옆의 ↺ 버튼으로 그 항목만 기본값으로 복원해요. 복원한 값도 되돌리기·다시 실행할 수 있어요.
- 설정 선택 › 테마 › 변경한 설정에서 기본값과 다른 항목을 모아 보고, 해당 설정으로 이동하거나 하나씩 복원해요. 저장한 액자·글꼴·스타일은 지우지 않아요.

## 3.8.9

- 설정값 변경 후 미리보기 높이를 먼저 맞춰 세부 설정의 스크롤 위치가 튀지 않도록 고쳤어요.
- 설정창 상단에 되돌리기·다시 실행을 추가했어요. 슬라이더 한 번의 조작을 한 단계로 묶고 어떤 값이 바뀌었는지 알림으로 보여줘요. 새로고침 전까지 최근 40단계를 보관해요.
- 설정 선택 목록의 테마·글자·채팅·이미지·프롬프트 제목을 더 크고 굵게 구분했어요.

- 색 선택 화면의 미리보기 옆에서 배경 테마색 농도를 조절해요. 화이트는 0.5~20%, 나이트는 1~20%이며 밝기별로 따로 저장해요. 직접 고친 배경색은 유지해요.

- 라이트의 내 말풍선·카드가 파란색으로 고정되던 문제를 고쳤어요. 고른 에이드의 형광펜 색을 옅게 반영하고 직접 고른 색은 유지해요.
- 에이드의 형광펜과 강조색을 더 맑고 부드럽게 다듬었어요. 화이트 공통 배경과 차콜 중심의 나이트는 유지해요.
- 요청 로그·예산 창의 선택 버튼 글자 대비를 개선하고 금액 카드의 짙은 파란 바탕을 옅은 패널 색으로 바꿨어요.
- 설정창에서 편집 모드를 없앴어요. 설정 선택·검색·전체 화면·닫기와 미리보기 조절은 그대로 사용할 수 있어요.
- 새 설정창에서 필요 없어진 상단 높이 감시와 글꼴 목록이 없는 화면의 빈 감시 객체를 정리했어요.
- 직접 테마 만들기의 미리보기 위에 예전 메뉴 높이만큼 빈틈이 남던 문제를 고쳤어요.

## 3.8.8

- 설정창을 미리보기와 세부 설정으로 나눴어요. PC에서는 좌우로, 모바일에서는 위아래로 보며 설정 선택과 검색은 한 메뉴에서 열어요.
- 세부 설정은 한 묶음씩 펼쳐요. 검색하면 해당 묶음을 바로 열고, 전체 화면·편집 모드·확대·이동·미리보기 높이 조절은 그대로 사용할 수 있어요.
- 라벤더·딸기·민트·오렌지·우드·수박 에이드를 추가했어요. 수박은 초록 형광펜과 빨간 강조를 사용해요.
- 화이트 배경은 블루 레몬에이드 기준으로 통일했어요. 나이트는 차콜에 각 테마색을 1%만 섞어 차분하게 맞추고 설명도 형광펜 색만 남겼어요. 직접 고른 커스텀 색은 유지해요.
- 대사 형광펜에 끝이 반듯한 직사각형을 추가했어요. 위치와 굵기를 조절할 수 있고 기존 펜 자국 모양으로도 돌아갈 수 있어요.

## 3.8.7

- 내 프로필을 '없음'으로 둔 말풍선·카드에서 글자가 왼쪽 테두리에 붙던 문제를 고쳤어요. 안쪽 여백이 양쪽 16px로 돌아와요.
- 카드 모양은 사진이 없을 때 왼쪽에 남던 사진 자리 틈을 없애 좌우 여백을 맞췄어요.
- 미리보기 높이 조절 손잡이와 접기 꺾쇠를 같은 중앙선에 맞췄어요. PC·모바일에서 전체 화면·편집 모드·접기·확대·높이 조절을 함께 사용하는 조합도 검사했어요.

## 3.8.6

- 설정창의 전체 화면 모드를 추가했어요. 검색창 옆에서 전체 화면과 작은 창을 바꾸고, 안에서 미리보기를 보면서 설정을 마칠 수 있어요.
- 편집 모드를 켜면 검색창·탭·카테고리를 잠시 숨겨 미리보기와 세부 설정에 집중할 수 있어요. 위쪽 편집 모드 끄기와 X는 그대로 남아요.
- 아래 닫기 줄을 없애고 검색창 오른쪽에 X 버튼을 넣었어요. 스크롤한 위치에서도 상단에서 바로 닫을 수 있어요.
- 미리보기 아래 손잡이를 위아래로 끌어 칸 높이를 바꿀 수 있어요. 마우스·손가락·방향키를 지원하며 기본 높이 버튼으로 되돌려요. 확대 배율과 높이는 별도로 조절해요.
- 설정창을 스크롤할 때 고정 탭과 미리보기 사이로 글자가 비치던 틈을 막았어요. 모바일 전체 화면에 기존 창 너비 제한이 남던 충돌도 고쳤어요.
- 미리보기의 마우스 휠 스크롤을 복원했어요. 끝에 닿으면 바깥 설정창을 스크롤하고, 접었다 펼쳐도 확대와 이동 상태를 유지해요.
- 글꼴 목록을 다시 그릴 때 남던 관찰자를 해제하고, 설정 팝업을 닫으면 글꼴·레이아웃·미리보기 자원도 정리해요. 캐릭터 프리셋 내보내기를 내 프로필로 잘못 찾던 검색도 수정했어요.

## 3.8.5

- 설정 검색을 추가했어요. QR 편집, 내 사진 오른쪽, 에셋 그림자처럼 기능 이름이나 자주 쓰는 표현을 입력하면 관련 설정으로 이동해요. 접혀 있거나 꺼져 있는 기능도 검색하며 검색어는 서버로 보내지 않아요.
- 미리보기에 확대·축소·원래 크기 버튼을 넣었어요. PC에서는 드래그와 방향키, 모바일에서는 두 손가락 확대·축소와 드래그를 사용해요. 50~300%로 볼 수 있고 실제 테마 설정값은 바뀌지 않아요.
- 내 프로필은 프로필 없음·작은 프로필·상단 큰 프로필 세 가지로 정리했어요. 기존 설정 유지 값은 이전 화면의 표시 상태에 맞춰 옮겨요.
- 수채화 프리셋의 사진 가장자리가 넓게 번지고 옅어지도록 다듬었어요. 딱딱한 테두리를 줄이고 긁힌 붓 자국은 남겼어요. 보관함에 저장한 액자는 바꾸지 않아요.
- 모바일에서 첫 메시지 밖의 ⋯ 메뉴가 화면 밖으로 열리던 조건을 재현해 확인했어요. 수정본에서 중간·마지막 메시지의 메뉴 위치와 버튼 클릭, 닫기를 함께 검사했어요.
- 검색 이동 중 생기는 예외와 미리보기 뒤에 설정이 가려지는 문제를 고쳤어요. 프로필·액자·그림자 회귀 검사와 텍스트 스트리밍 중 불필요한 이미지 재계산 여부도 확인했어요.

## 3.8.4

- 내 프로필을 따로 꾸며요. 기존 설정 유지·프로필 없음·작은 사진·상단 큰 사진을 고르고, 작은 사진은 왼쪽 또는 오른쪽에 놓아요. 처음에는 기존 화면을 유지해요.
- 내 큰 프로필도 크기·세로 자르기·위치·흐림·모서리·장식 액자와 이름 글꼴·색·정렬·시간 및 버튼 배치를 캐릭터와 독립적으로 조절해요. 액자 보관함은 함께 써요.
- 수채화는 사진 자체를 번진 물감 모양으로 자르고 가장자리에 흐림과 드라이 브러시 흔적을 넣었어요. 맥 브라우저를 얇게 다듬고 프리셋 안쪽 글자를 없앴어요.
- 팝 스타를 살짝 기울어진 종이 두 장의 겹친 메모지로 다듬었어요. 리본 끈과 별은 사진 위에, 낙서 노트의 레몬 스티커는 종이 밖으로 보이게 고쳤어요. 저장해 둔 액자는 그대로 남아요.
- 장식 액자의 그림자가 사라지던 스타일 충돌을 고쳤어요. 에셋·캐릭터·내 프로필 모두 액자 외곽을 따라 그림자를 만들고 색·진하기·가로/세로·번짐·확장을 미리보기와 채팅에 같이 반영해요. 큰 프로필의 흐림 설정을 덮어쓰던 규칙도 고쳤어요.
- 내 프로필도 원본 사진은 화면 가까이 왔을 때만 불러오고, 기존 사진 관찰자를 함께 써요. 기본 액자 썸네일은 편집 캐시와 분리해 설정창을 열 때 반복해서 그리지 않아요.

설정: **채팅 › 내 프로필 / 내 이름·시간**. 캐릭터는 **채팅 › 캐릭터 프로필 / 캐릭터 이름·시간**에서 따로 조절해요.

## 3.8.3

- 기본 액자를 물든 수채화·맥 브라우저·스크랩 다이어리·리본 포스트·팝 스타·낙서 노트 6종으로 바꿨어요. 기존에 저장한 액자는 그대로 남아요.
- 프리셋의 바탕색·포인트색과 가로·세로 비율(각 50~200%)을 조절해요. 조절을 마치면 장식을 새 비율로 다시 그려요. 프로필과 에셋에 각각 적용하고 보관함에 저장해요.
- 직접 불러온 액자도 가로·세로를 따로 늘이거나 줄일 수 있어요. 원래 그림 전체가 함께 변형돼요.
- 이름 정렬과 버튼 배치에 따라 … 메뉴가 화면 밖으로 잘리던 문제를 고쳤어요. 메뉴는 화면 안에 배치하고 공간이 부족하면 안쪽을 스크롤해요.
- 글자만 갱신될 때 액자·모서리 처리를 반복하지 않게 줄였어요. 다른 확장이 사진을 교체하거나 지웠을 때 빈 액자 틀이 남는 문제도 고쳤어요.

## 3.8.2

- 장식 액자에 샴페인·실버 라인·필름·코너 장식 프리셋과 공용 보관함을 추가했어요. 최대 12개를 저장하고 이름 변경·선택·삭제할 수 있어요.
- 불러온 액자는 자동으로 보관함에 저장해요. 프로필과 에셋에서 함께 쓰며 새로고침 후에도 남아요.
- 전체 보이기에서 빈 공간 대신 실제 사진 경계에 모서리 둥글기가 적용되도록 고쳤어요. 설정 미리보기에도 같은 보정이 적용돼요.
- 프로필 없음·작은 프로필·상단 큰 프로필을 명확히 구분했어요. 기존 숨김 상태는 유지하고 직접 선택한 표시 방식이 적용돼요.
- 액자 설정 박스의 위아래 여백과 버튼 정렬을 맞췄어요. 북마크 메모 정규식은 북마크 1.3.1에서 함께 수정했어요.

## 3.8.1

- 이미지 모양 설정의 SHAPES 오류와 재접속 후 설정창이 비는 문제를 고쳤어요. 한 항목에서 오류가 나도 다른 설정으로 이동할 수 있어요.
- 프로필에 본문 폭·가로 꽉·작게 배치와 픽셀·화면 높이 비율·사진 비율을 추가했어요. 세로로 남길 부분과 사진 위치도 조절해요.
- 이름·시간·버튼·생성 정보를 왼쪽·가운데·오른쪽으로 함께 맞추고 모델 아이콘을 시간 옆으로 돌렸어요.
- 모바일 액자 선택 버튼이 설명과 겹치지 않게 고치고, 이미 저장한 액자도 안쪽 사진 모서리를 조절할 수 있게 했어요.
- 북마크의 속마음 색 보정이 새로 열린 내용에도 적용돼요. 트래커 뒤 줄바꿈 제거는 북마크 1.3.0과 함께 사용해 주세요.

## 3.8.0

- 채팅 › 프로필에서 캐릭터 사진을 본문 위에 크게 놓고 크기·자르기·위치·모서리·흐림을 조절할 수 있어요. 기본은 기존 작은 프로필이에요.
- 채팅 › 이름·시간에서 이름 글꼴·크기·굵기·자간·색·정렬·외곽선·그림자를 바꾸고, 시간과 버튼을 이름 옆 또는 아래 한 줄·두 줄로 배치해요.
- 에셋과 큰 프로필에 장식 PNG 액자를 넣을 수 있어요. 배경을 지우고 사진이 들어갈 안쪽을 확인하거나 직접 영역을 지정해요.
- 기본 테두리를 얇은 선·안쪽 선·은은한 빛·이중선으로 정리하고 선 종류·색·여백·그림자 조절을 더했어요.
- 사용하지 않는 팝업 감시와 PC의 주기적인 여백 검사를 줄이고, 글자색 보정은 바뀐 메시지만 확인해요.
