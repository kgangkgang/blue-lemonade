# Blue Lemonade

SillyTavern용 테마와 선택형 내장 확장 모음입니다.

<!-- start-guide:begin -->
## 설치

1. 실리태번 **확장 탭 › 확장 설치**에 `https://github.com/kgangkgang/blue-lemonade` 를 붙여 넣고 **설치**를 눌러요.
   ZIP 으로 깔 때는 풀어서 `data/default-user/extensions/blue-lemonade` 에 넣어요 (폴더 바로 안에 `manifest.json`).
2. 새로고침하면 테마가 바로 켜져요. 설정은 확장 탭의 **Blue Lemonade** 서랍이나 요술봉 메뉴의 **Blue Lemonade** 에서 열어요.

도구별 사용법은 설정 창 각 확장 머리의 ? 도움말에 있어요.

## 업데이트

새 판이 나오면 확장 서랍 머리 · 설정 창 제목의 판 알약이 노랗게 빛나요. 누르면 바뀐 내역과 업데이트 단추가 나와요. 실리태번 확장 관리의 업데이트로도 받을 수 있어요.
테마 › 기타 설정 › 새 버전 자동 확인으로 알림을 끌 수 있어요.
