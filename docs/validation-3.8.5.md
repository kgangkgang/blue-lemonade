# 3.8.5 검증 기록

- Chromium의 1280×900 PC 화면과 390×820 모바일 화면에서 각각 307개 검사 통과: 설정 검색·미리보기 조작 119, 내 프로필 91, 액자 그림자 19, 액자·모서리 34, 색상·비율·메뉴 44.
- 실리태번의 실제 메시지 메뉴 클릭 처리 코드를 사용한 별도 재현에서 PC·모바일 각각 48개 검사 통과. 첫 메시지뿐 아니라 중간·마지막 메시지와 사용자 메시지의 표시 위치, 클릭 대상, 닫기를 검사함.
- 구버전 재현에서는 같은 모바일 조건의 48개 중 14개가 실패했으며, 수정본에서는 모두 통과함.
- 액자 가로·세로 비율 30개, 수채화 투명도·장식 겹침·프리셋 이전·캐시 15개 검사 통과.
- 기존 설정 이전, 원본 사진 지연 로딩, 액자 영역 판별, 관찰자 해제 등 별도 코드 회귀 검사와 전체 52개 JavaScript 파일의 구문 검사 통과.
- 텍스트 100회 및 마크업 100회 스트리밍 모의 검사에서 액자·프로필 모듈이 예약한 재계산은 각각 0회. 전체 실리태번의 응답 속도나 API 생성 속도를 측정한 수치는 아님.
- 3.8.4 대비 실행 코드·CSS 약 25KB, 테마 ZIP 약 10KB 증가. 검색은 로컬에서 수행하고 미리보기 배율은 테마 설정에 저장하지 않음.

모바일 검사는 좁은 화면과 합성 터치 입력을 사용한 재현이다. 실제 Android·iOS 기기와 설치된 모든 외부 확장의 조합을 보증하는 결과는 아니다.
